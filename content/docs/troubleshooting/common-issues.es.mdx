## ¿Necesito el modo offline? [#do-i-need-offline-mode]

No. SkinsRestorer funciona con autenticación online y offline. Mantén tu política de autenticación. Un backend detrás de un proxy tiene sus propios requisitos de reenvío.

## ¿Necesito una base de datos para una red? [#do-i-need-a-database-for-a-network]

Las skins normales gestionadas por el proxy no necesitan SQL. Un plugin de backend que usa la API en modo proxy necesita almacenamiento compartido en MySQL o PostgreSQL.

Lee [modo proxy](/docs/troubleshooting/proxy-mode) antes de cambiar el almacenamiento.

## ¿Por qué clear no siempre muestra a Steve? [#why-does-clear-not-always-show-steve]

`/skin clear` quita la selección guardada. Después, el jugador tiene la skin de su cuenta, o una [skin predeterminada](/docs/configuration/default-skins) si el servidor configura una.

## ¿Por qué no cambia la imagen de la URL después de editarla? [#why-does-the-url-image-not-change-after-i-edit-it]

El servidor guarda la textura que creó MineSkin. No vuelve a leer la imagen. Sube el PNG corregido y ejecuta el nuevo comando. `/skin update` solo actualiza las skins copiadas de una cuenta de jugador.

## ¿Puedo usar una imagen de capa personalizada? [#can-i-use-a-custom-cape-image]

No. La web solo ofrece una lista de capas existentes. Lee [compatibilidad con capas](/docs/features/capes).

## ¿Un estado en verde significa que todos los servicios funcionan? [#does-a-green-status-mean-all-services-work]

No. `/sr status` comprueba los servicios de UUID y perfiles de cuentas. MineSkin, las subidas desde la web, las recomendaciones y el acceso a la base de datos necesitan sus propias comprobaciones.
