Поиск скина может не сработать из-за DNS, TLS, заблокированного HTTPS, ошибки внешнего сервиса или ограничения частоты запросов. Запишите точную ошибку, прежде чем менять правила файрвола.

## Найдите проблемный сервис [#narrow-down-the-service]

1. Выполните `/sr status` на проблемном сервере или прокси.
2. Попробуйте одно известное имя игрока.
3. Если проблема с созданием скина по URL, попробуйте один правильный URL скина.
4. Сохраните соответствующую ошибку из консоли.

`/sr status` проверяет сервисы UUID и профилей аккаунтов. Он не проверяет все запросы к MineSkin, рекомендации, загрузку через сайт и вашу базу данных.

Если имена аккаунтов работают, а URL нет, проверьте сервис создания скинов по URL и ключ. Успешный результат `/sr status` не доказывает, что создание по URL работает.

## Проверьте локальные настройки [#check-local-configuration]

Для обычной работы с интернетом оставьте `advanced.noConnections: false`. Значение true запрещает новые внешние запросы, создание скинов по URL и проверку обновлений.

Если ошибка связана с TLS, проверьте системное время и хранилище сертификатов Java. Не отключайте проверку сертификатов, чтобы скрыть проблему TLS.

## Исходящие подключения [#outbound-access]

Серверу нужны разрешение имён DNS и исходящий HTTPS на порт 443. Разрешите ответный трафик для установленных соединений. Для сервисов скинов не нужно открывать новый входящий порт.

В [справочнике по сети](/docs/reference/network) найдите адрес для функции, которая не работает. Адреса API и перенаправления загрузок могут меняться между релизами.

Попросите хостинг проверить подключение именно из окружения сервера Minecraft. Успешный запрос с вашего компьютера не доказывает, что у сервера есть доступ.

## Ограничения частоты запросов [#rate-limits]

Подождите перед повторными попытками. Оставьте обычное время кеширования. Уменьшение `storage.skinExpiresAfter` или `storage.uuidExpiresAfter` увеличивает число запросов.

`api.mojangBatchWindowSeconds` управляет группировкой запросов к Mojang. Эта настройка не увеличивает лимиты загрузки MineSkin.

## Защита внутренних серверов [#protect-proxy-backends]

Защита внутренних серверов задаётся отдельным правилом для входящих подключений. Разрешите подключения только от вашего прокси или доверенной сети. Устаревшее (legacy) перенаправление не может проверить произвольное прямое подключение.

Используйте [руководство PaperMC по безопасности внутренних серверов](https://docs.papermc.io/velocity/security/). Настройте аутентификацию на публичном прокси в соответствии с политикой вашего сервера.
