Escolha o resultado que você vê. Mudar vários valores de configuração ao mesmo tempo torna a causa mais difícil de encontrar.

## Escolha o sintoma [#choose-your-symptom]

| Sintoma | Guia |
| --- | --- |
| O comando funciona, mas a skin não muda | [Skin não aparece](/docs/troubleshooting/no-skin) |
| O comando é negado | [Permissão negada](/docs/troubleshooting/permissions) |
| A skin some ao entrar, mudar de mundo ou trocar de servidor | [A skin é redefinida](/docs/troubleshooting/skin-resets) |
| O backend avisa sobre o modo proxy ou uma API indisponível | [Modo proxy e API do backend](/docs/troubleshooting/proxy-mode) |
| A skin de uma conta ou URL não carrega | [Conexões com os serviços](/docs/troubleshooting/firewall) |
| O envio ou a geração falha | [Problemas de envio](/docs/troubleshooting/uploads) |
| Apenas um cliente vê a skin errada | [Substituições do cliente ou launcher](/docs/troubleshooting/launcher-issues) |
| Um plugin, mod ou fork muda o resultado | [Conflitos](/docs/troubleshooting/incompatibility-list) |

Para respostas rápidas, leia as [perguntas frequentes](/docs/troubleshooting/common-issues). Se essas verificações não explicarem o problema, colete [diagnósticos para o suporte](/docs/troubleshooting/debugging).

## Envie evidências úteis [#report-useful-evidence]

Um relato útil inclui o comando exato, o erro completo, as versões, a sua configuração e o resultado depois de reconectar. Uma captura de tela de uma skin que não mudou não basta para identificar a etapa que falhou.
