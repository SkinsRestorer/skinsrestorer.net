Выберите результат, который вы действительно видите. Если менять несколько настроек сразу, причину найти сложнее.

## Выберите симптом [#choose-your-symptom]

| Симптом | Руководство |
| --- | --- |
| Команда выполнилась, но скин не изменился | [Скин не отображается](/docs/troubleshooting/no-skin) |
| Команда запрещена | [Нет разрешения](/docs/troubleshooting/permissions) |
| Скин пропадает после входа, смены мира или перехода на другой сервер | [Скин сбрасывается](/docs/troubleshooting/skin-resets) |
| Внутренний сервер предупреждает о режиме прокси или недоступном API | [Режим прокси и API внутреннего сервера](/docs/troubleshooting/proxy-mode) |
| Не загружается скин аккаунта или URL | [Подключение к сервисам](/docs/troubleshooting/firewall) |
| Не удаётся загрузить или создать скин | [Проблемы с загрузкой](/docs/troubleshooting/uploads) |
| Неправильный скин виден только на одном клиенте | [Замена скина клиентом или лаунчером](/docs/troubleshooting/launcher-issues) |
| Плагин, мод или форк меняет результат | [Конфликты](/docs/troubleshooting/incompatibility-list) |

Короткие ответы собраны в разделе [частые вопросы](/docs/troubleshooting/common-issues). Если эти проверки не объясняют проблему, соберите [диагностику для поддержки](/docs/troubleshooting/debugging).

## Соберите полезные данные [#report-useful-evidence]

В полезном отчёте есть точная команда, полный текст ошибки, версии, описание конфигурации и результат после переподключения. Одного снимка экрана с неизменившимся скином недостаточно, чтобы найти шаг, на котором произошёл сбой.
