## Do I need offline mode?

No. SkinsRestorer supports online and offline authentication. Keep your authentication policy. A proxy backend has separate forwarding requirements.

## Do I need a database for a network?

Ordinary proxy-managed skins do not require SQL. A backend API consumer in proxy mode needs shared MySQL or PostgreSQL storage.

Read [proxy mode](/docs/troubleshooting/proxy-mode) before you change storage.

## Why does clear not always show Steve?

`/skin clear` removes the saved selection. Account skin lookup and default skin rules determine the result afterward.

## Why does the URL image not change after I edit it?

A generated URL skin is a cached signed texture. Upload the revised PNG and select the new result. `/skin update` refreshes account skin data.

## Can I use a custom cape image?

The website supports selected existing capes through its generation route. It does not accept arbitrary cape PNGs or grant account ownership.

Read [cape support](/docs/features/capes).

## Does a green status mean all services work?

No. `/sr status` checks account UUID and profile services. MineSkin, website uploads, recommendations, and database access need their own checks.
