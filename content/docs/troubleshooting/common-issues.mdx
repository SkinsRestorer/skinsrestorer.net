This page lists common causes of SkinsRestorer problems.

## Host-specific issues

Your Minecraft hosting provider can restrict the plugin.

### Servers with a forced proxy

Some providers, such as Minehut, force servers to use a proxy that customers cannot configure.

If that proxy manages skins and capes, it can override SkinsRestorer. Ask the hosting provider whether you can disable its skin system.

### Servers with a misconfigured firewall

A hosting firewall can block the SkinsRestorer APIs. If `/sr status` reports connection errors, follow the [firewall guide](/docs/troubleshooting/firewall).

## Platform-specific issues

Unsupported server software can cause errors.

### Supported platforms

We only support the following platforms:

- Bukkit
- Spigot
- Paper and supported forks, such as Purpur and Pufferfish
- Folia
- BungeeCord (and forks like Waterfall)
- Velocity
- Latest Fabric
- Latest NeoForge

Hybrid platforms such as Magma, Mohist, and Cardboard are not supported.

## Plugin-specific issues

Other plugins can change player profiles and override SkinsRestorer.

### Plugins with known issues

Read the [incompatibility list](/docs/troubleshooting/incompatibility-list). If a plugin is listed, contact its developer.

## Client-specific issues

Some launchers include a skin system that overrides server skins. Follow the [launcher guide](/docs/troubleshooting/launcher-issues) to disable it.
