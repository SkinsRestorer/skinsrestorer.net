Elige el resultado que ves. Si cambias varios valores de configuración a la vez, será más difícil encontrar la causa.

## Elige tu síntoma [#choose-your-symptom]

| Síntoma | Guía |
| --- | --- |
| El comando funciona, pero la skin no cambia | [Skin no visible](/docs/troubleshooting/no-skin) |
| Se deniega el comando | [Permiso denegado](/docs/troubleshooting/permissions) |
| La skin desaparece al entrar, cambiar de mundo o cambiar de servidor | [La skin se restablece](/docs/troubleshooting/skin-resets) |
| Un backend avisa sobre el modo proxy o una API no disponible | [Modo proxy y API del backend](/docs/troubleshooting/proxy-mode) |
| No se puede cargar la skin de una cuenta o una URL | [Conexiones con los servicios](/docs/troubleshooting/firewall) |
| Falla la subida o la generación | [Problemas al subir skins](/docs/troubleshooting/uploads) |
| Solo un cliente ve la skin incorrecta | [Sustituciones del cliente o lanzador](/docs/troubleshooting/launcher-issues) |
| Un plugin, mod o fork cambia el resultado | [Conflictos](/docs/troubleshooting/incompatibility-list) |

Para respuestas rápidas, lee las [preguntas frecuentes](/docs/troubleshooting/common-issues). Si estas comprobaciones no explican el problema, recopila [diagnósticos para el soporte](/docs/troubleshooting/debugging).

## Aporta pruebas útiles [#report-useful-evidence]

Un informe útil incluye el comando exacto, el error completo, las versiones, tu configuración y el resultado después de reconectarte. Una captura de una skin que no cambia no basta para saber qué paso falló.
