O site gera um comando. Depois, o seu servidor executa esse comando. Descubra qual etapa falha antes de tentar de novo.

## O site rejeita o arquivo [#the-website-rejects-the-file]

Use uma skin em PNG no formato padrão. O limite de arquivo do site é de 5 MB. Uma imagem de skin precisa ser quadrada ou ter o dobro da largura em relação à altura. Os tamanhos padrão são 64×64 e 64×32. Versões em escala dessas proporções também passam na verificação da prévia.

Se a página informar outras dimensões, exporte a imagem com um editor de skins. Renomear uma captura de tela não a transforma em uma skin.

Se a prévia 3D não estiver disponível, você ainda pode enviar ou gerar sua skin. A prévia precisa de suporte a WebGL no navegador.

Se a prévia mostrar espaços vazios nos braços, alterne entre **Clássico** e **Fino**. Leia [o guia de modelos](/docs/features/skin-design).

## A geração falha ou fica esperando [#generation-fails-or-waits]

1. Leia o erro abaixo de **A skin não foi enviada**. A linha seguinte diz o que tentar. Sua skin e suas opções são mantidas.
   - Com **Axolotl**, tente novamente ou mude para **Oficial** em **Opções avançadas**.
   - Com **Oficial**, confira sua chave de API do MineSkin em **Opções avançadas** e tente novamente.
2. Confira a lista de capas disponíveis se o erro for de acesso a capas. Se a lista mostrar **Não foi possível carregar as capas**, selecione **Tentar novamente** abaixo dela.

No modo **Axolotl**, um envio com capa selecionada vai para o Axolotl, o serviço do SkinsRestorer para enviar skins com capa. Envios sem capa e o modo **Oficial** usam o MineSkin diretamente. Esses caminhos podem falhar de forma independente.

Enquanto uma tarefa está pendente, o botão de gerar mostra **Gerando…** e fica desativado. Uma tarefa pode levar até um minuto. Para parar de esperar, selecione **Parar de esperar** abaixo do botão e gere novamente.

Se o MineSkin não terminar em 2 minutos, a página para de esperar e mostra um erro. A tarefa ainda pode terminar, então espere alguns minutos antes de gerar de novo.

Se você mudar o arquivo, o modelo, a capa, a chave de API ou o método de envio, a página para de esperar o resultado anterior. Sair da página também para a espera. Uma tarefa que o serviço já aceitou pode continuar. A página não reenvia essa tarefa automaticamente.

## O comando gerado falha [#the-generated-command-fails]

Mantenha a URL entre aspas e o valor do modelo gerado sem alterações. Um valor `skinsrestorer-axolotl://` é uma entrada válida para o comando. Ele não é um link para o navegador. Execute um resultado `/skin url` no chat do jogo para o seu próprio jogador.

Execute um resultado `/sr createcustom` como administrador no proxy (ou no servidor, se você não tiver proxy). Ele cria uma skin com nome. Ele não seleciona a skin para um jogador.

Confira `skinsrestorer.command.set.url` e as [restrições de URL](/docs/configuration/restrict-skins). Se a geração funcionou mas o servidor não consegue carregar o resultado, confira as [conexões com os serviços](/docs/troubleshooting/firewall).

## Relate um problema [#report-a-problem]

Informe a etapa, o texto do erro, o modelo, se você escolheu uma capa e se usou uma chave de API. Não inclua a chave em si.

Use os [diagnósticos para o suporte](/docs/troubleshooting/debugging) para um erro no servidor.
