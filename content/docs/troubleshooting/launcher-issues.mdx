Some Minecraft launchers use their own skin system.
That system can replace skins from SkinsRestorer.

## TLauncher

Disable TLauncher skins to show server skins.

### CAUTION: TLauncher can contain malware

<Callout type="error" emoji="💣">
  Do not use TLauncher.
  It can expose your account or computer to malware.

  For more information, watch the [video by TheMisterEpic](https://www.youtube.com/watch?v=SBTH9n6lz9o).

</Callout>

### How to fix

If you continue to use TLauncher, disable its skin feature.

#### Disable or turn off TLauncher skins

1. Open TLauncher.
2. Select `Accounts`.
3. Select `Configure account`.
4. Clear the `Use skins TLauncher` checkbox.
5. Select `Yes`.
6. Close the `Accounts` window.

## SKlauncher

SKlauncher can override server skins.
Enable Compatibility Mode to disable its skin system.

### How to fix

1. Open SKlauncher.
2. Open `Installations Manager`.
3. Edit the installation that you use for the server.
4. Enable `Compatibility Mode`.
5. Save the installation.
6. Start Minecraft again.

Compatibility Mode applies to one installation.
Repeat these steps for each installation that uses SkinsRestorer.

For more information, see the
[official SKlauncher documentation](https://docs.skmedix.pl/faq/launcher-related#can-i-use-clients-mods-resource-packs-shaders-etc-in-sklauncher).

## Crystal Launcher

Crystal Launcher can override server skins.

### How to fix

1. Open **Launcher Settings**.
2. Select **Advanced**.
3. Enable **Disable Crystal Launcher skin system**.
4. Restart Minecraft.

## Legacy Launcher / TL Legacy

Legacy Launcher can apply Ely.by skins to offline accounts.
These skins override SkinsRestorer.

### How to fix

1. Open the **Account Manager**.
2. Select the Free/offline account you use to play.
3. Edit the account.
4. Disable **Use Ely.by skins**.
5. Save the account and restart Minecraft.

If you use an Ely.by account, change to a normal free or offline account first.

## HMCL

HMCL can use its own skin system for offline accounts.
This system can override SkinsRestorer.

### How to fix

1. Open the **Account List**.
2. Select your offline account.
3. Click **Upload/Edit Skin**.
4. Select **Default**.
5. Save the change and restart Minecraft.

Do not select Steve, Alex, a local file, LittleSkin, or Blessing Skin.
These options enable the HMCL skin system.

## PCL2 / Plain Craft Launcher 2

The custom offline skin option in PCL2 uses a resource pack.
This pack replaces player skins on your computer.

### How to fix

1. Open **Settings**.
2. Open the **Launch** settings.
3. Find **Offline Skin**.
4. Click **Reset Skin**, or change the skin type from **Custom** to **Random**.
5. Restart Minecraft.
