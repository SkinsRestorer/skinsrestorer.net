A client mod or launcher skin system can replace the skin sent by the server. SkinsRestorer cannot detect which launcher a player uses.

## Compare clients

1. Apply a known skin with `/skin set xknat`.
2. Ask another player to check your appearance.
3. Join with an unmodified Java client.
4. Compare the results.

If the unmodified client shows the correct skin, the server's skin property works. Inspect the affected client's mods and skin-system configuration.

## Remove the override

Disable custom skin or cape replacements in the affected client. Choose official/server-provided skins if the client offers that option. Restart the client and reconnect.

Exact controls depend on the launcher and version. Use the launcher's current instructions instead of an old screenshot or video.

Minecraft's Skin Customization controls only show or hide outer-layer parts. They do not choose a different server skin.

## About the launcher warning

The offline-mode warning is general advice. It does not identify your launcher. `/skin notification ignore-cracked-client` hides that warning for your player.

Hiding the warning does not fix a client override.

## If all clients look wrong

Return to [no visible skin](/docs/troubleshooting/no-skin). Collect [diagnostics](/docs/troubleshooting/debugging) if the server-side application fails.
