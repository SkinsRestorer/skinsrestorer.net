La web genera un comando. Después, tu servidor ejecuta ese comando. Averigua qué etapa falla antes de volver a intentarlo.

## La web rechaza el archivo [#the-website-rejects-the-file]

Usa una plantilla de skin en PNG. El límite de archivo de la web es de 5 MB. Una imagen de skin debe ser cuadrada o el doble de ancha que de alta. Los tamaños estándar son 64×64 y 64×32. Las versiones escaladas de estas proporciones también pasan la comprobación de la vista previa.

Si la página indica otras dimensiones, exporta la imagen con un editor de skins. Cambiar el nombre de una captura de pantalla no la convierte en una skin.

Si la vista previa 3D no está disponible, puedes subir o generar tu skin igualmente. La vista previa necesita que tu navegador admita WebGL.

Si la vista previa muestra huecos en los brazos, cambia entre **Clásica** y **Delgada**. Lee [la guía de modelos](/docs/features/skin-design).

## La generación falla o se queda esperando [#generation-fails-or-waits]

1. Lee el error debajo de **La skin no se subió**. La línea siguiente te dice qué probar. Tu skin y tus opciones se mantienen.
   - Con **Axolotl**, inténtalo de nuevo o cambia a **Oficial** en **Opciones avanzadas**.
   - Con **Oficial**, revisa tu clave de API de MineSkin en **Opciones avanzadas** y vuelve a intentarlo.
2. Revisa la lista de capas disponibles si el error tiene que ver con el acceso a capas. Si la lista muestra **No se pudieron cargar las capas**, pulsa **Reintentar** debajo de ella.

En el modo **Axolotl**, una subida con capa seleccionada va a Axolotl, el servicio de SkinsRestorer para subir skins con capa. Las subidas sin capa y el modo **Oficial** usan MineSkin directamente. Estas rutas pueden fallar por separado.

Mientras un trabajo está pendiente, el botón de generar muestra **Generando…** y queda desactivado. Un trabajo puede tardar hasta un minuto. Para dejar de esperar, pulsa **Dejar de esperar** debajo del botón y vuelve a generar.

Si MineSkin no termina en 2 minutos, la página deja de esperar y muestra un error. El trabajo aún puede terminar, así que espera unos minutos antes de volver a generar.

Si cambias el archivo, el modelo, la capa, la clave de API o el método de subida, la página deja de esperar el resultado anterior. Salir de la página también deja de esperar. Un trabajo que el servicio ya aceptó puede continuar. La página no vuelve a enviar ese trabajo automáticamente.

## Falla el comando generado [#the-generated-command-fails]

Mantén la URL entre comillas y el valor del modelo generado sin cambios. Un valor `skinsrestorer-axolotl://` es una entrada válida para el comando. No es un enlace para el navegador. Ejecuta un resultado `/skin url` en el chat del juego para tu propio jugador.

Ejecuta un resultado `/sr createcustom` como administrador en el proxy (o en el servidor, si no tienes proxy). Crea una skin con nombre. No asigna la skin a ningún jugador.

Revisa `skinsrestorer.command.set.url` y las [restricciones de URL](/docs/configuration/restrict-skins). Si la generación funcionó pero el servidor no puede cargar el resultado, revisa las [conexiones con los servicios](/docs/troubleshooting/firewall).

## Informa de un problema [#report-a-problem]

Incluye la etapa, el texto del error, el modelo, si elegiste una capa y si usaste una clave de API. No incluyas la clave.

Usa los [diagnósticos para el soporte](/docs/troubleshooting/debugging) si el error ocurre en el servidor.
