Choose the result that you actually see. Changing several configuration values at once makes the cause harder to find.

## Choose your symptom

| Symptom | Guide |
| --- | --- |
| Command succeeds, skin stays unchanged | [No visible skin](/docs/troubleshooting/no-skin) |
| Command is denied | [Permission denied](/docs/troubleshooting/permissions) |
| Skin disappears after a join, world change, or server switch | [Skin resets](/docs/troubleshooting/skin-resets) |
| Backend warns about proxy mode or an unavailable API | [Proxy mode and backend API](/docs/troubleshooting/proxy-mode) |
| Account skin or URL cannot load | [Service connections](/docs/troubleshooting/firewall) |
| Upload or generation fails | [Upload problems](/docs/troubleshooting/uploads) |
| Only one client sees the wrong skin | [Client and launcher overrides](/docs/troubleshooting/launcher-issues) |
| A plugin, mod, or fork changes the result | [Conflicts](/docs/troubleshooting/incompatibility-list) |

For quick answers, read [common questions](/docs/troubleshooting/common-issues). If these checks do not explain the problem, collect [diagnostics for support](/docs/troubleshooting/debugging).

## Report useful evidence

A useful report includes the exact command, full error, versions, setup, and the result after reconnecting. A screenshot of an unchanged skin alone does not identify the failed step.
