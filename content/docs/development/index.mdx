The public API gives Java plugins access to skin storage, player selections, generation services, and platform skin application.

## Start here

1. Build [your first plugin](/docs/development/first-plugin) with a complete Bukkit example.
2. Read [dependencies and lifecycle](/docs/development/api) for other build tools and platforms.
3. Choose [persistent or temporary application](/docs/development/storage).
4. Configure [backend API access](/docs/development/proxy-api) for a proxy network.

The examples target **API 15.12.6**. Use the same API major as the installed plugin. Do not bundle the API or depend on internal implementation classes.

## API resources

- [Public Javadocs](https://jd.skinsrestorer.net).
- [Release API source](https://github.com/SkinsRestorer/SkinsRestorer/tree/15.12.6/api/src/main/java/net/skinsrestorer/api).
- [Upstream example plugin](https://github.com/SkinsRestorer/SkinsRestorerAPIExample).

The [skin lifecycle](/docs/development/inner-workings) explains identifiers, signed properties, and join resolution. Use [support diagnostics](/docs/troubleshooting/debugging) when an integration behaves differently from ordinary commands.
