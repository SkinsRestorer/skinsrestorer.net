SkinsRestorer shows player skins on Minecraft servers. It works on online-mode and offline-mode servers.

Players can change their skin with one command. Server networks can also share cached skin data.

## Why use SkinsRestorer?

SkinsRestorer works on a single server or a large proxy network.

The default permissions work without another plugin.
If you need more control, use a permissions plugin.

### Main features

- Apply a custom skin with `/skin url "<url>"`.
- Create a shared server skin with `/sr createcustom`.
- Use cached skins when Mojang is unavailable.
- Replace the default Steve and Alex skins.
- Apply skin changes without reconnecting.
