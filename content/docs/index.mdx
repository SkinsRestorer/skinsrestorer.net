SkinsRestorer lets players change their Minecraft Java Edition skin on a server. Server owners can restore account skins, offer custom skins, and manage who can change them.

## Find the right guide

- **New server owner:** Start with [installation](/docs/installation). A proxy network needs SkinsRestorer on the proxy and every backend.
- **Player:** Read [change or reset your skin](/docs/features/change-skin). Your server must provide SkinsRestorer and permission to use it.
- **Administrator:** Configure [player access](/docs/configuration/player-access), [default skins](/docs/configuration/default-skins), or [shared storage](/docs/configuration/database).
- **Developer:** Start with the [first plugin tutorial](/docs/development/first-plugin), then read about [persistent and temporary changes](/docs/development/storage).

Exact command syntax and configuration keys live in the [reference](/docs/reference). The [skin lifecycle](/docs/development/inner-workings) explains why a visible skin and a saved selection can differ.

## Version and support

These guides target **SkinsRestorer 15.12.6**. Each page shows its applicable platform and review date. Minecraft and Java requirements depend on the platform and download.

Use the [compatibility guide](/docs/installation/requirements) before you install a mod or update a server. For a support request, collect a [diagnostic report and recent log](/docs/troubleshooting/debugging).
