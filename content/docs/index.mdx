SkinsRestorer restores player skins on offline-mode Minecraft servers and networks. Players can change their skin with one command.

SkinsRestorer can also cache skins across large networks.

## Why use SkinsRestorer?

SkinsRestorer works on both online-mode and offline-mode Minecraft servers.

It supports small servers, role-play servers, and large networks.

The default permissions work without a permissions plugin. You can add a permissions plugin for more control.

### Special features

- Apply a custom skin with `/skin url "<url>"`.
- Create a custom skin for the server with `/sr createcustom`.
- Use cached skins when Mojang is unavailable.
- Replace the default Steve and Alex skins.
- Apply skin changes without reconnecting.
