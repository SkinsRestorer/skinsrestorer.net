Esta guía trata de un servidor NeoForge independiente. Si el backend está detrás de un proxy, configura también el reenvío con la [guía de Velocity](/docs/installation/velocity) y revisa el [modo proxy](/docs/troubleshooting/proxy-mode).

## Antes de empezar [#before-you-start]

Descarga el mod que corresponde a tu versión de Minecraft. SkinsRestorer 15.12.6 es para Minecraft 26.3. Lee los [requisitos](/docs/installation/requirements) antes de actualizar un modpack existente.

Usa un loader de NeoForge compatible. La compilación 15.12.6 es para NeoForge 26.3.0.7-beta.

## Instalar [#install]

1. Detén el servidor.
2. Descarga el archivo de NeoForge de la [versión oficial](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Quita los JAR antiguos del mod SkinsRestorer de `mods`. Conserva la configuración y los datos.
4. Pon el JAR nuevo del mod en `mods`.
5. Inicia el servidor.
6. Revisa el registro para buscar errores de dependencias del loader y errores de SkinsRestorer al arrancar.

El mod guarda su configuración en `config/skinsrestorer/config.yml`, dentro de la carpeta del servidor. No copies un JAR del plugin de Bukkit en `mods`.

## Comprueba [#check]

1. Conéctate al servidor.
2. Ejecuta `/skin set xknat` en el chat del juego.
3. Pide a otro jugador que revise tu skin.
4. Reconéctate y comprueba que la selección se mantiene.

Si se deniega el acceso, configura los permisos de la plataforma o lee [acceso de jugadores](/docs/configuration/player-access). Si el loader rechaza el mod, compara las versiones de Minecraft, Java y el loader con los requisitos del archivo.
