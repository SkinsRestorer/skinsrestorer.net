Read the [main installation page](/docs/installation) before you install SkinsRestorer.

<Callout type="warning" emoji="🆕">
  The NeoForge mod supports **only the latest Minecraft release**. It does not support older versions.
</Callout>

<Callout type="info" emoji="🔁">
  On a supported version, the NeoForge mod works like the Bukkit plugin. It uses the same features and configuration.
</Callout>

## Install the mod

These steps also apply to Forge forks that can load NeoForge mods.

<Steps>
  <Step>
    ### Install NeoForge
    Download the latest NeoForge installer from [neoforged.net](https://neoforged.net/). Install it for the newest Minecraft version.
  </Step>

  <Step>
    ### Create or update the mods folder
    Run the generated `run.bat` or `run.sh` file once. NeoForge creates its folders, including `mods`.

    If NeoForge is already installed, update it to the latest build.
  </Step>

  <Step>
    ### Add SkinsRestorer
    Download the latest SkinsRestorer mod from [Modrinth](https://modrinth.com/mod/skinsrestorer). Put it in the server's `mods` folder.
  </Step>

  <Step>
    ### Start the server
    Start the server. Read the console for errors or missing dependencies.
  </Step>

  <Step>
    ### Make sure that the mod works
    Run `/skinsrestorer status` or `/sr status` in the game or server console.
  </Step>

  <Step>
    ### Configure SkinsRestorer
    Edit the files in `config/SkinsRestorer/`. The [configuration guide](/docs/configuration) explains each option.
  </Step>
</Steps>
