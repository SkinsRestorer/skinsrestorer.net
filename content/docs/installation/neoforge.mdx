This guide covers a NeoForge server. For a backend behind a proxy, also follow the [Velocity guide](/docs/installation/velocity) and install NeoForwarding or NeoVelocity for forwarding. SkinsRestorer detects the proxy only when one of these mods is installed.

## Before you start

Match the mod download to your Minecraft version. SkinsRestorer 15.12.6 targets Minecraft 26.3. Read the [requirements](/docs/installation/requirements) before you update an existing modpack.

Use a matching NeoForge loader. The 15.12.6 build targets NeoForge 26.3.0.7-beta.

## Install

1. Stop the server.
2. Download `SkinsRestorer-Mod-NeoForge-15.12.6.jar` from the [official release](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Remove older SkinsRestorer mod JARs from `mods`. Keep the configuration and data.
4. Put the new mod JAR in `mods`.
5. Start the server.
6. Read the log for loader dependency errors and SkinsRestorer startup errors.

The mod keeps its configuration in `config/skinsrestorer/config.yml` inside the server folder. Do not put `SkinsRestorer.jar` in `mods`. That file is the plugin for Paper and proxies.

## Check

Complete the [first skin check](/docs/installation/quick-start). It tests the command, what other players see, and a reconnect.

If access is denied, configure the platform's permissions or read [player access](/docs/configuration/player-access). If the loader rejects the mod, compare your Minecraft, Java, and loader versions with the [requirements](/docs/installation/requirements).
