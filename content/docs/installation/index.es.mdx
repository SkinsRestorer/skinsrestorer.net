Elige el software que recibe las conexiones de los jugadores. No elijas un archivo solo por su nombre.

## Elige tu configuración [#choose-your-setup]

| Configuración | Guía | Dónde se ejecuta SkinsRestorer |
| --- | --- | --- |
| Un servidor Paper, Spigot o Bukkit | [Paper / Spigot](/docs/installation/bukkit) | Carpeta `plugins` del servidor |
| Red Velocity | [Velocity](/docs/installation/velocity) | Proxy y todos los servidores de la red |
| Red BungeeCord | [BungeeCord](/docs/installation/bungeecord) | Proxy y todos los servidores de la red |
| Servidor Fabric independiente | [Fabric](/docs/installation/fabric) | Carpeta `mods` del servidor |
| Servidor NeoForge independiente | [NeoForge](/docs/installation/neoforge) | Carpeta `mods` del servidor |

El plugin de servidor/proxy y los mods de Fabric y NeoForge se descargan por separado. Un plugin de Bukkit no funciona como mod de Fabric.

## Antes de empezar [#before-you-start]

1. Lee los [requisitos](/docs/installation/requirements) de tu plataforma.
2. Descarga un archivo de las [versiones oficiales](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Haz una copia de seguridad de la configuración y los datos de SkinsRestorer.
4. Sigue una guía de instalación.
5. Completa la [primera prueba de skin](/docs/installation/quick-start).

SkinsRestorer funciona con autenticación online y offline. No desactives la autenticación para instalarlo. Los servidores detrás de un proxy necesitan su propia configuración de reenvío de datos.
