Run this check after your [platform installation](/docs/installation). Each step tests one part: that you can use the command, that the server can download the skin, and that other players see it.

## First change

1. Join the server with a Java client.
2. In the game chat, run `/skin set xknat`. `xknat` is the name of a Minecraft account with a custom skin.
3. Wait for the success message.
4. Ask another player to check your appearance. If you are alone, press `F5` to see your character from behind.
5. Disconnect and join again.

Your selected skin must remain after you reconnect. Your own client can briefly show an older skin, so use another player's view too when you can.

## Proxy network check

1. Connect through the proxy address.
2. Change your skin on the first backend.
3. Switch to a second backend.
4. Check your skin again.

If it changes on one backend only, use [proxy troubleshooting](/docs/troubleshooting/proxy-mode). Do not add a database just because the network has several servers.

## Return to your account skin

Run `/skin clear`. This removes the skin that you selected. You then get the skin of your Minecraft account, or a [default skin](/docs/configuration/default-skins) if the server sets one.

## If a check fails

| Result | Next step |
| --- | --- |
| Unknown command | Read the server console from the start for a SkinsRestorer error, and check that you installed the correct file for your platform. Also check that `commands.disableSkinCommand` is `false` in `config.yml` |
| Permission denied | [Check permissions](/docs/troubleshooting/permissions) |
| Name or URL cannot load | [Check service connections](/docs/troubleshooting/firewall) |
| Success message, unchanged skin | [Check profile application](/docs/troubleshooting/no-skin) |
| Selection disappears after reconnect | [Check join and proxy behavior](/docs/troubleshooting/skin-resets) |

## Next

After these checks pass, set up the server for your players:

- [Grant player access](/docs/configuration/player-access) to choose which players can use skin commands. On a proxy network, set permissions on the proxy.
- [Set default skins](/docs/configuration/default-skins) for players without their own skin.
- Read [Manage your server](/docs/configuration) for the other settings, such as the skin menu and storage.

Players can read [change or reset a skin](/docs/features/change-skin).
