Run this check after your [platform installation](/docs/installation). It separates command access, skin fetching, and profile application.

## First change

1. Join the server with a Java client.
2. Run `/skin set xknat`.
3. Wait for the success message.
4. Ask another player to check your appearance.
5. Disconnect and join again.

Your selected skin must remain after you reconnect. Your own client can briefly show an older skin, so use another player's view too.

## Proxy network check

1. Connect through the proxy address.
2. Change your skin on the first backend.
3. Switch to a second backend.
4. Check your skin again.

If it changes on one backend only, use [proxy troubleshooting](/docs/troubleshooting/proxy-mode). Do not add a database just because the network has several servers.

## Return to your account skin

Run `/skin clear`. This removes your saved selection. Account lookup and server default rules then determine your skin.

## If a check fails

| Result | Next step |
| --- | --- |
| Unknown command | Read the startup log and check the installed artifact |
| Permission denied | [Check permissions](/docs/troubleshooting/permissions) |
| Name or URL cannot load | [Check service connections](/docs/troubleshooting/firewall) |
| Success message, unchanged skin | [Check profile application](/docs/troubleshooting/no-skin) |
| Selection disappears after reconnect | [Check join and proxy behavior](/docs/troubleshooting/skin-resets) |

After these checks pass, read [change or reset a skin](/docs/features/change-skin).
