Выберите ПО, которое принимает подключения игроков. Не выбирайте сборку только по имени файла.

## Выберите конфигурацию [#choose-your-setup]

| Конфигурация | Руководство | Где работает SkinsRestorer |
| --- | --- | --- |
| Один сервер Paper, Spigot или Bukkit | [Paper / Spigot](/docs/installation/bukkit) | Папка `plugins` сервера |
| Сеть Velocity | [Velocity](/docs/installation/velocity) | Прокси и каждый внутренний сервер |
| Сеть BungeeCord | [BungeeCord](/docs/installation/bungeecord) | Прокси и каждый внутренний сервер |
| Отдельный сервер Fabric | [Fabric](/docs/installation/fabric) | Папка `mods` сервера |
| Отдельный сервер NeoForge | [NeoForge](/docs/installation/neoforge) | Папка `mods` сервера |

Плагин для серверов и прокси и моды Fabric и NeoForge скачиваются отдельно. Плагин Bukkit не работает как мод Fabric.

## Перед началом [#before-you-start]

1. Прочитайте [требования](/docs/installation/requirements) для вашей платформы.
2. Скачайте сборку из [официального релиза](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Создайте резервную копию настроек сервера и данных SkinsRestorer.
4. Выполните одно руководство по установке.
5. Проведите [первую проверку скина](/docs/installation/quick-start).

SkinsRestorer работает с online и offline аутентификацией. Не отключайте аутентификацию ради установки. Для внутренних серверов за прокси нужна отдельная настройка перенаправления данных игроков.
