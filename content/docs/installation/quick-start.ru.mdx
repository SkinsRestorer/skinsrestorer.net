Выполните эту проверку после [установки на вашу платформу](/docs/installation). Каждый шаг проверяет одну часть: что вы можете использовать команду, что сервер может скачать скин и что другие игроки его видят.

## Первая смена скина [#first-change]

1. Зайдите на сервер с клиента Java Edition.
2. Выполните в чате игры `/skin set xknat`. Здесь `xknat` означает имя аккаунта Minecraft со своим скином.
3. Дождитесь сообщения об успехе.
4. Попросите другого игрока посмотреть на ваш вид. Если вы на сервере одни, нажмите `F5`, чтобы увидеть персонажа со спины.
5. Отключитесь и зайдите снова.

Выбранный скин должен сохраниться после переподключения. Ваш клиент может ненадолго показать старый скин, поэтому по возможности проверьте и вид у другого игрока.

## Проверка сети с прокси [#proxy-network-check]

1. Подключитесь по адресу прокси.
2. Смените скин на первом внутреннем сервере.
3. Перейдите на второй внутренний сервер.
4. Снова проверьте скин.

Если скин меняется только на одном внутреннем сервере, откройте [решение проблем с прокси](/docs/troubleshooting/proxy-mode). Не добавляйте базу данных только потому, что в сети несколько серверов.

## Возврат скина аккаунта [#return-to-your-account-skin]

Выполните `/skin clear`. Команда удаляет выбранный вами скин. После этого у вас будет скин вашего аккаунта Minecraft или [скин по умолчанию](/docs/configuration/default-skins), если сервер его задаёт.

## Если проверка не прошла [#if-a-check-fails]

| Результат | Что делать |
| --- | --- |
| Неизвестная команда | Найдите ошибку SkinsRestorer в консоли сервера с самого начала запуска и проверьте, что установлен правильный файл для вашей платформы. Также проверьте, что `commands.disableSkinCommand` в `config.yml` равно `false` |
| Нет разрешения | [Проверьте разрешения](/docs/troubleshooting/permissions) |
| Не удаётся загрузить имя или URL | [Проверьте подключение к сервисам](/docs/troubleshooting/firewall) |
| Сообщение об успехе, но скин не изменился | [Проверьте применение профиля](/docs/troubleshooting/no-skin) |
| Выбранный скин пропадает после переподключения | [Проверьте вход и работу прокси](/docs/troubleshooting/skin-resets) |

## Дальше [#next]

Когда все проверки пройдены, настройте сервер для игроков:

- [Выдайте доступ игрокам](/docs/configuration/player-access), чтобы выбрать, кто может использовать команды скинов.
- [Настройте скины по умолчанию](/docs/configuration/default-skins) для игроков без своего скина.
- Прочитайте раздел [Управление сервером](/docs/configuration) об остальных настройках, например о меню скинов и хранилище.

Игроки могут прочитать руководство [смена и сброс скина](/docs/features/change-skin).
