В каждом релизе три файла:

- `SkinsRestorer.jar`: плагин для Paper, Spigot, BungeeCord и Velocity.
- `SkinsRestorer-Mod-Fabric-<version>.jar`: мод для Fabric.
- `SkinsRestorer-Mod-NeoForge-<version>.jar`: мод для NeoForge.

## Плагины для серверов и прокси [#server-and-proxy-plugins]

Используйте сборку для серверов и прокси на серверах, совместимых с Bukkit, а также на BungeeCord и Velocity. У сборки 15.12.6 такие требования:

| Требование | 15.12.6 |
| --- | --- |
| Java | 8 или новее |
| Paper и другие серверы, совместимые с Bukkit | Minecraft от 1.8 до 26.1.1 |
| Velocity | от 3.0 до 3.4 |
| BungeeCord и Waterfall | Waterfall от 1.17 до 1.21 |

Эти диапазоны релиз указывает на [Hangar](https://hangar.papermc.io/SRTeam/SkinsRestorer). Они взяты из [конфигурации сборки релиза](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/gradle.properties).

Платформе может требоваться более новая Java, чем SkinsRestorer. Проверьте [требования Paper](https://docs.papermc.io/paper/getting-started/) или [требования Velocity](https://docs.papermc.io/velocity/getting-started/) для вашей версии.

Форки и гибридные серверы для модов и плагинов могут менять работу с профилями игроков. Успешный запуск ещё не доказывает совместимость. Прежде чем сообщать о [конфликте с платформой](/docs/troubleshooting/incompatibility-list), воспроизведите проблему на оригинальной платформе.

## Fabric и NeoForge 15.12.6 [#fabric-and-neoforge-15126]

Исходный код этого релиза рассчитан на **Minecraft 26.3**. Метаданные Fabric требуют Java 25 или новее и Fabric Loader 0.16.0 или новее. Сборка использует Fabric Loader 0.19.5.

Сборка NeoForge рассчитана на NeoForge 26.3.0.7-beta. Используйте загрузчик и версию Java, которые требует этот релиз Minecraft. Для более старого сервера Minecraft нужна соответствующая старая сборка мода SkinsRestorer.

Эти значения взяты из [конфигурации сборки релиза](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/gradle.properties) и [метаданных Fabric](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/mod/fabric/src/main/resources/fabric.mod.json).

## Клиенты и сети [#clients-and-networks]

Игрокам ничего не нужно устанавливать. Плагин и моды работают только на сервере или прокси. Сервер сам передаёт свойства скина клиентам Java Edition. Моды скинов на клиенте могут заменять эти свойства.

Прежде чем искать проблемы со скинами в сети с прокси, настройте правильное перенаправление UUID и профилей. Для Velocity используйте [официальное руководство по перенаправлению](https://docs.papermc.io/velocity/player-information-forwarding/).

Клиенты Bedrock и сторонние системы отрисовки на клиенте могут обрабатывать скины по-своему. Не используйте их отображение как единственную проверку смены скина на сервере Java Edition.

## Загрузка и зависимости [#downloads-and-dependencies]

JAR для Fabric включает Fabric API, Cloud и Fabric permissions API. JAR для NeoForge включает Cloud. Если загрузчик сообщает об отсутствующей зависимости, проверьте, что JAR мода подходит к вашим версиям Minecraft и загрузчика.

Перейдите к [руководству по установке](/docs/installation).
