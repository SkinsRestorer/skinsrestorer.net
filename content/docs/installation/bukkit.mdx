By the end of this guide, your server will load SkinsRestorer and accept a skin change.

## Before you start

You need file access, console access, and a supported [Java runtime](/docs/installation/requirements). If players connect through a proxy, use the [Velocity](/docs/installation/velocity) or [BungeeCord](/docs/installation/bungeecord) guide instead.

## Install

1. Stop the server.
2. Download the server/proxy JAR from the [15.12.6 release](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Remove older SkinsRestorer JARs from `plugins`. Keep the existing data folder.
4. Put the new JAR in `plugins`.
5. Start the server.
6. Read the console for SkinsRestorer startup errors.

The plugin creates `plugins/SkinsRestorer/config.yml`. Keep the defaults for this first check. Do not use the server-wide `/reload` command to install or update plugins.

## Check the installation

1. Join the server with a Java client.
2. Run `/skin set xknat`.
3. Ask another player to check your skin.
4. Reconnect and check that the selection remains.

If the command is unavailable, check the startup log and `commands.disableSkinCommand`. If access is denied, read [player access](/docs/configuration/player-access).

If the command succeeds but the skin stays unchanged, use [no visible skin](/docs/troubleshooting/no-skin).
