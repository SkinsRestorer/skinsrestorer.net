## Install the plugin

<Steps>
  <Step>
    ### Download the plugin
    Download the latest version from [Modrinth](https://modrinth.com/plugin/skinsrestorer).
  </Step>

<Step>
  ### Add the plugin
  Put `SkinsRestorer.jar` in the `plugins` folder.
</Step>

<Step>
  ### Restart the server
  Restart the server with `/restart` or `/stop`.

  CAUTION: Do not use `/reload` or PlugMan. These tools can break SkinsRestorer.
</Step>

<Step>
  ### Make sure that the plugin works
  Run `/plugins`. SkinsRestorer must appear in green.

  If SkinsRestorer is red or absent, read the server log for errors.
</Step>

  <Step>
    ### Configure the plugin
    Continue to the [configuration guide](/docs/configuration).
  </Step>
</Steps>
