Cada versão tem três arquivos:

- `SkinsRestorer.jar`: o plugin para Paper, Spigot, BungeeCord e Velocity.
- `SkinsRestorer-Mod-Fabric-<version>.jar`: o mod para Fabric.
- `SkinsRestorer-Mod-NeoForge-<version>.jar`: o mod para NeoForge.

## Plugins de servidor e proxy [#server-and-proxy-plugins]

Na versão 15.12.6, o `SkinsRestorer.jar` tem estes requisitos:

| Requisito | 15.12.6 |
| --- | --- |
| Java | 8 ou mais recente |
| Paper e outros servidores compatíveis com Bukkit | Minecraft 1.8 a 26.1.1 |
| Velocity | 3.0 a 3.4 |
| BungeeCord e Waterfall | Waterfall 1.17 a 1.21 |

Essas faixas são as que a versão declara no [Hangar](https://hangar.papermc.io/SRTeam/SkinsRestorer). Elas vêm da [configuração de build da versão](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/gradle.properties).

A plataforma pode exigir um Java mais novo do que o SkinsRestorer. Leia os [requisitos do Paper](https://docs.papermc.io/paper/getting-started/) ou os [requisitos do Velocity](https://docs.papermc.io/velocity/getting-started/) para a sua versão exata.

Forks e servidores híbridos de mods e plugins podem mudar o comportamento dos perfis. Iniciar sem erros não prova que o servidor é compatível. Reproduza o problema na plataforma original antes de relatar um [conflito de plataforma](/docs/troubleshooting/incompatibility-list).

## Fabric e NeoForge 15.12.6 [#fabric-and-neoforge-15126]

O código desta versão é para o **Minecraft 26.3**. Os metadados do Fabric exigem Java 25 ou mais recente e Fabric Loader 0.16.0 ou mais recente. A build usa o Fabric Loader 0.19.5.

A build do NeoForge é para o NeoForge 26.3.0.7-beta. Use o loader e o Java exigidos por essa versão do Minecraft. Um servidor com uma versão mais antiga do Minecraft precisa de um mod do SkinsRestorer mais antigo e correspondente.

Esses valores vêm da [configuração de build da versão](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/gradle.properties) e dos [metadados do Fabric](https://github.com/SkinsRestorer/SkinsRestorer/blob/15.12.6/mod/fabric/src/main/resources/fabric.mod.json).

## Clientes e redes [#clients-and-networks]

Os jogadores não instalam nada. O plugin e os mods rodam apenas no servidor ou no proxy. O servidor envia as propriedades da skin para os clientes Java. Mods de skin no cliente podem substituir essas propriedades.

Uma rede com proxy precisa de um encaminhamento correto de UUID e perfis antes de você investigar problemas de skin. No Velocity, use o [guia oficial de encaminhamento](https://docs.papermc.io/velocity/player-information-forwarding/).

Clientes Bedrock e renderizadores personalizados podem tratar skins de outra forma. Não use apenas a aparência neles para conferir uma troca de skin em um servidor Java.

## Downloads e dependências [#downloads-and-dependencies]

O JAR para Fabric inclui a Fabric API, o Cloud e a API de permissões do Fabric. O JAR para NeoForge inclui o Cloud. Se o loader indicar uma dependência ausente, confira se o JAR do mod corresponde às suas versões do Minecraft e do loader.

Continue com [o seu guia de instalação](/docs/installation).
