Before you start, read the [main installation page](/docs/installation).

<Callout type="warning" emoji="🆕">
  The Fabric mod supports **only the latest Minecraft release**. It does not support older versions.
</Callout>

<Callout type="info" emoji="🔁">
  On a supported version, the Fabric mod works like the Bukkit plugin.
  It uses the same commands, configuration, and permissions.
</Callout>

## Install the mod

<Steps>
  <Step>
    ### Prepare your server
    Install [Fabric Loader](https://fabricmc.net/use/server/) for the latest Minecraft version.

    If Fabric is already installed, update it to the latest release.
  </Step>

  <Step>
    ### Install dependencies
    Download the matching [Fabric API](https://modrinth.com/mod/fabric-api) version.
    Put the file in the server's `mods` folder.
  </Step>

  <Step>
    ### Add SkinsRestorer
    Download the latest SkinsRestorer mod from [Modrinth](https://modrinth.com/mod/skinsrestorer).
    Put it in the same `mods` folder.
  </Step>

  <Step>
    ### Start the server
    Start or restart the Fabric server.
    Read the console for warnings or missing dependencies.
  </Step>

  <Step>
    ### Make sure that the mod works
    Join the server and run `/skinsrestorer status`.
  </Step>

  <Step>
    ### Configure SkinsRestorer
    Edit the files in `config/SkinsRestorer/`.
    The [configuration guide](/docs/configuration) explains each option.
  </Step>
</Steps>

## Need help?

If you need help, save the latest server log.
Send the log and your Fabric Loader version on our [Discord server](https://skinsrestorer.net/discord).
