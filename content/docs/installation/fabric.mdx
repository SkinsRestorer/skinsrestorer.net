This guide covers a standalone Fabric server. A proxy backend also needs compatible profile forwarding and proxy mode.

## Before you start

Match the mod download to your Minecraft version. SkinsRestorer 15.12.6 targets Minecraft 26.3. Read the [requirements](/docs/installation/requirements) before you update an existing modpack.

The packaged Fabric release includes Fabric API, Cloud, and the permissions API. Do not use the raw development JAR.

## Install

1. Stop the server.
2. Download the Fabric artifact from the [official release](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Remove older SkinsRestorer mod JARs from `mods`. Keep the configuration and data.
4. Put the new mod JAR in `mods`.
5. Start the server.
6. Read the log for loader dependency errors and SkinsRestorer startup errors.

Use the configuration location reported by the mod. Do not copy a Bukkit plugin JAR into `mods`.

## Check

1. Join the server.
2. Run `/skin set xknat`.
3. Ask another player to check your skin.
4. Reconnect and check that the selection remains.

If access is denied, configure the platform's permissions or read [player access](/docs/configuration/player-access). If the loader rejects the mod, compare Minecraft, Java, and loader versions with the artifact requirements.
