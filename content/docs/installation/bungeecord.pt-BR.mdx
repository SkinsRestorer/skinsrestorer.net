O SkinsRestorer funciona no BungeeCord e em cada backend. O proxy gerencia os comandos de skin e envia o perfil escolhido para os backends.

## Antes de começar [#before-you-start]

Você precisa de acesso ao proxy e a todos os backends. O encaminhamento legacy exige proteção dos backends. Leia [segurança dos backends](/docs/troubleshooting/firewall#protect-proxy-backends) antes de abrir a rede para os jogadores.

## Configure o encaminhamento [#configure-forwarding]

1. Pare o proxy e os backends.
2. Ative o encaminhamento de IP na configuração do proxy.
3. Mantenha `online_mode: true` no `config.yml` do BungeeCord. O proxy verifica as contas dos jogadores.
4. Ative o encaminhamento do BungeeCord em cada backend Bukkit.
5. Desative a autenticação de contas nos backends.

```yaml title="config.yml do BungeeCord (trecho)"
online_mode: true
ip_forward: true
```

```yaml title="spigot.yml do backend (trecho)"
settings:
  bungeecord: true
```

```properties title="server.properties do backend (trecho)"
online-mode=false
```

Só os backends usam `online-mode=false`. Não coloque `online_mode: false` no proxy para fazer as skins funcionarem.

## Instalar [#install]

1. Coloque o `SkinsRestorer.jar` na pasta `plugins` do proxy.
2. Instale a mesma versão em todos os backends.
3. Inicie os backends e o proxy.
4. Leia todos os logs de inicialização.

Um backend Fabric ou NeoForge precisa do JAR do mod correspondente e de um mod de encaminhamento. Leia o guia do [Fabric](/docs/installation/fabric) ou do [NeoForge](/docs/installation/neoforge). Mantenha `server.proxyMode.detection` como `AUTO` nos backends, a menos que a detecção falhe.

## Confira [#check]

Conclua o [primeiro teste de skin](/docs/installation/quick-start), incluindo uma troca entre backends. Conceda as permissões dos comandos no BungeeCord ou no plugin de permissões do proxy.

As skins comuns gerenciadas pelo proxy não exigem armazenamento SQL. Integrações com a API nos backends precisam de [armazenamento compartilhado em MySQL ou PostgreSQL](/docs/configuration/database). Para configurar a API, leia [o guia da API no proxy](/docs/development/proxy-api).

## Se falhar [#if-it-fails]

Se apenas um backend mostrar a skin, compare a configuração de encaminhamento e a versão instalada dele com as de um backend que funciona. Consulte [problemas no modo proxy](/docs/troubleshooting/proxy-mode) para avisos de modo e comandos duplicados.
