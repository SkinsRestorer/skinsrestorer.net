Это руководство описывает отдельный сервер NeoForge. Внутреннему серверу за прокси также нужны совместимое перенаправление профилей и режим прокси.

## Перед началом [#before-you-start]

Скачайте мод для вашей версии Minecraft. SkinsRestorer 15.12.6 рассчитан на Minecraft 26.3. Прочитайте [требования](/docs/installation/requirements), прежде чем обновлять существующий модпак.

Используйте подходящую версию загрузчика NeoForge. Сборка 15.12.6 рассчитана на NeoForge 26.3.0.7-beta.

## Установка [#install]

1. Остановите сервер.
2. Скачайте сборку для NeoForge из [официального релиза](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Удалите старые JAR-файлы мода SkinsRestorer из `mods`. Настройки и данные оставьте.
4. Положите новый JAR мода в `mods`.
5. Запустите сервер.
6. Проверьте лог на ошибки зависимостей загрузчика и ошибки запуска SkinsRestorer.

Используйте папку настроек, которую указывает мод. Не копируйте JAR плагина Bukkit в `mods`.

## Проверка [#check]

1. Зайдите на сервер.
2. Выполните `/skin set xknat`.
3. Попросите другого игрока посмотреть на ваш скин.
4. Переподключитесь и убедитесь, что выбранный скин сохранился.

Если доступ запрещён, настройте разрешения платформы или прочитайте раздел [доступ игроков](/docs/configuration/player-access). Если загрузчик отклоняет мод, сравните версии Minecraft, Java и загрузчика с требованиями сборки.
