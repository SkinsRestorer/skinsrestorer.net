Это руководство описывает сервер NeoForge. Если сервер работает за прокси, также выполните [руководство для Velocity](/docs/installation/velocity) и установите NeoForwarding или NeoVelocity для перенаправления. SkinsRestorer обнаруживает прокси, только если установлен один из этих модов.

## Перед началом [#before-you-start]

Скачайте мод для вашей версии Minecraft. SkinsRestorer 15.12.6 рассчитан на Minecraft 26.3. Прочитайте [требования](/docs/installation/requirements), прежде чем обновлять существующий модпак.

Используйте подходящую версию загрузчика NeoForge. Сборка 15.12.6 рассчитана на NeoForge 26.3.0.7-beta. JAR для NeoForge включает Cloud. Отдельно его устанавливать не нужно.

## Установка [#install]

1. Остановите сервер.
2. Скачайте `SkinsRestorer-Mod-NeoForge-15.12.6.jar` из [официального релиза](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Удалите старые JAR-файлы мода SkinsRestorer из `mods`. Настройки и данные оставьте.
4. Положите новый JAR мода в `mods`.
5. Запустите сервер.
6. Проверьте лог на ошибки зависимостей загрузчика и ошибки запуска SkinsRestorer.

Мод хранит настройки в файле `config/skinsrestorer/config.yml` в папке сервера. Не кладите `SkinsRestorer.jar` в `mods`. Это плагин для Paper и прокси.

## Проверка [#check]

Выполните [первую проверку скина](/docs/installation/quick-start). Она проверяет команду, то, что видят другие игроки, и переподключение.

Если доступ запрещён, настройте разрешения платформы или прочитайте раздел [доступ игроков](/docs/configuration/player-access). Если загрузчик отклоняет мод, сравните версии Minecraft, Java и загрузчика с [требованиями](/docs/installation/requirements).
