SkinsRestorer se ejecuta en BungeeCord y en cada backend. El proxy gestiona los comandos de skin y envía el perfil elegido a los backends.

## Antes de empezar [#before-you-start]

Necesitas acceso al proxy y a todos los backends. El reenvío legacy exige proteger los backends. Lee [seguridad de los backends](/docs/troubleshooting/firewall#protect-proxy-backends) antes de abrir la red a los jugadores.

## Configura el reenvío [#configure-forwarding]

1. Detén el proxy y los backends.
2. Activa el reenvío de IP en la configuración del proxy.
3. Deja `online_mode: true` en el `config.yml` de BungeeCord. El proxy comprueba las cuentas de los jugadores.
4. Activa el reenvío de BungeeCord en cada backend Bukkit.
5. Desactiva la autenticación de cuentas en los backends.

```yaml title="config.yml de BungeeCord (fragmento)"
online_mode: true
ip_forward: true
```

```yaml title="spigot.yml del backend (fragmento)"
settings:
  bungeecord: true
```

```properties title="server.properties del backend (fragmento)"
online-mode=false
```

Solo los backends usan `online-mode=false`. No pongas `online_mode: false` en el proxy para que funcionen las skins.

## Instalar [#install]

1. Pon `SkinsRestorer.jar` en la carpeta `plugins` del proxy.
2. Instala la misma versión en todos los backends.
3. Inicia los backends y el proxy.
4. Revisa todos los registros de arranque.

Un backend Fabric o NeoForge necesita el JAR del mod correspondiente y un mod de reenvío. Lee la guía de [Fabric](/docs/installation/fabric) o de [NeoForge](/docs/installation/neoforge). Deja `server.proxyMode.detection` en `AUTO` en los backends salvo que la detección falle.

## Comprobar [#check]

Completa la [prueba de la primera skin](/docs/installation/quick-start), incluido un cambio entre backends. Los comandos de skin se ejecutan en el proxy. Para limitarlos, lee [acceso de jugadores en BungeeCord](/docs/configuration/player-access#bungeecord).

Las skins normales gestionadas por el proxy no necesitan almacenamiento SQL. Las integraciones con la API en los backends necesitan [almacenamiento compartido en MySQL o PostgreSQL](/docs/configuration/database). Para configurar la API, lee [la guía de la API en el proxy](/docs/development/proxy-api).

## Si falla [#if-it-fails]

Si solo un backend muestra la skin, compara su configuración de reenvío y la versión instalada con las de un backend que funcione. Consulta [problemas del modo proxy](/docs/troubleshooting/proxy-mode) si ves avisos de modo o comandos duplicados.
