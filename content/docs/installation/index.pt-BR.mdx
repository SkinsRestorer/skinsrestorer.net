Escolha o software que recebe as conexões dos jogadores. Não escolha um arquivo apenas pelo nome.

## Escolha sua configuração [#choose-your-setup]

| Configuração | Guia | Onde o SkinsRestorer funciona |
| --- | --- | --- |
| Um servidor Paper, Spigot ou Bukkit | [Paper / Spigot](/docs/installation/bukkit) | Pasta `plugins` do servidor |
| Rede Velocity | [Velocity](/docs/installation/velocity) | Proxy e todos os servidores da rede |
| Rede BungeeCord | [BungeeCord](/docs/installation/bungeecord) | Proxy e todos os servidores da rede |
| Servidor Fabric independente | [Fabric](/docs/installation/fabric) | Pasta `mods` do servidor |
| Servidor NeoForge independente | [NeoForge](/docs/installation/neoforge) | Pasta `mods` do servidor |

O plugin de servidor/proxy e os mods do Fabric e NeoForge são downloads separados. Um plugin Bukkit não funciona como mod Fabric.

## Antes de começar [#before-you-start]

1. Leia os [requisitos](/docs/installation/requirements) da sua plataforma.
2. Baixe um arquivo das [versões oficiais](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Faça uma cópia de segurança da configuração e dos dados do SkinsRestorer.
4. Siga um guia de instalação.
5. Conclua o [primeiro teste de skin](/docs/installation/quick-start).

O SkinsRestorer funciona com autenticação online e offline. Não desative a autenticação para instalá-lo. Servidores atrás de um proxy precisam de uma configuração própria de encaminhamento de dados.
