Choose the software that accepts your players' connections. Do not choose an artifact by its filename alone.

## Choose your setup

| Setup | Installation guide | Where SkinsRestorer runs |
| --- | --- | --- |
| One Paper, Spigot, or Bukkit server | [Paper / Spigot](/docs/installation/bukkit) | The server's `plugins` folder |
| Velocity network | [Velocity](/docs/installation/velocity) | The proxy and every backend |
| BungeeCord network | [BungeeCord](/docs/installation/bungeecord) | The proxy and every backend |
| Standalone Fabric server | [Fabric](/docs/installation/fabric) | The server's `mods` folder |
| Standalone NeoForge server | [NeoForge](/docs/installation/neoforge) | The server's `mods` folder |

The server/proxy plugin and the Fabric/NeoForge mods are separate downloads. A Bukkit plugin does not run as a Fabric mod.

## Before you start

1. Read the [requirements](/docs/installation/requirements) for your platform.
2. Download an artifact from the [official releases](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Back up the server configuration and existing SkinsRestorer data.
4. Follow one installation guide.
5. Complete the [first skin check](/docs/installation/quick-start).

SkinsRestorer works with online and offline server authentication. Do not disable authentication just to install it. Proxy backends require their own forwarding configuration.
