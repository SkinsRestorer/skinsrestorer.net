Ao final deste guia, seu servidor vai carregar o SkinsRestorer e aceitar uma troca de skin.

## Antes de começar [#before-you-start]

Você precisa de acesso aos arquivos, acesso ao console e uma [versão do Java](/docs/installation/requirements) compatível. Se os jogadores se conectam por um proxy, use o guia do [Velocity](/docs/installation/velocity) ou do [BungeeCord](/docs/installation/bungeecord).

## Instalar [#install]

1. Pare o servidor.
2. Baixe o `SkinsRestorer.jar` da [versão 15.12.6](https://github.com/SkinsRestorer/SkinsRestorer/releases/tag/15.12.6).
3. Remova JARs antigos do SkinsRestorer da pasta `plugins`. Mantenha a pasta de dados existente.
4. Coloque o novo JAR em `plugins`.
5. Inicie o servidor.
6. Leia o console procurando erros do SkinsRestorer na inicialização.

O plugin cria `plugins/SkinsRestorer/config.yml`. Mantenha os valores padrão neste primeiro teste. Não use o comando `/reload` do servidor inteiro para instalar ou atualizar plugins.

## Confira a instalação [#check-the-installation]

Faça o [primeiro teste de skin](/docs/installation/quick-start). Ele testa o comando, o que outros jogadores veem e uma reconexão. Ele também mostra o que fazer se uma etapa falhar.
