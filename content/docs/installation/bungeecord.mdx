Before you start, read the [main installation page](/docs/installation).

## Install the plugin

<Callout type="info" emoji="ℹ️">
  Install SkinsRestorer on the proxy and every backend server.
  Some features do not work without the backend installation.
</Callout>

<Callout type="info" emoji="ℹ️">
  Waterfall uses the same installation process.
  SkinsRestorer does not support FlameCord, Aegis, or other BungeeCord-like proxies.
</Callout>

<Steps>
  <Step>
    ### Download the plugin
    Download the latest version from [Modrinth](https://modrinth.com/plugin/skinsrestorer).
  </Step>

<Step>
  ### Install the proxy plugin
  Put `SkinsRestorer.jar` in the `plugins` folder of the **BungeeCord proxy**.
</Step>

<Step>
  ### Install the backend plugin
  Put `SkinsRestorer.jar` in the `plugins` folder of **every Spigot server**.
</Step>

  <Step>
    ### Configure player information forwarding
    Follow the [BungeeCord forwarding guide](https://www.spigotmc.org/wiki/bungeecord-installation/#post-installation).
    SkinsRestorer needs forwarding to communicate with backend servers.

    Make sure that these values are set:

    ```yaml filename="spigot.yml" /true/
    settings:
    bungeecord: true
    ```

    ```properties filename="server.properties" /false/
    online-mode=false
    ```

  </Step>

<Step>
  ### Restart the network
  Restart all Spigot servers and the BungeeCord proxy.
  Use `/restart`, `/stop`, or `/end`.
</Step>

  <Step>
    ### Make sure that Proxy Mode is active
    Find this message in the log of each Spigot server:
    ```ansi filename="logs/latest.log"
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m----------------------------------------------
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m +==================+
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m | SkinsRestorer |
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m |------------------|
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m | [33;1mProxy Mode[32;22m |
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m +==================+
    [33;1m[[32;22mSkinsRestorer[33;1m] [32;22m----------------------------------------------
    ```
    If the message is absent, make sure that player information forwarding is correct.

  </Step>

<Step>
  ### Configure the plugin
  [Configure SkinsRestorer](/docs/configuration) on the BungeeCord proxy.
</Step>

<Step>
  ### Copy the configuration
  Copy the same `plugins/SkinsRestorer/config.yml` file to the proxy and every backend server.
</Step>

<Step>
  ### Restart the network again
  Restart all Spigot servers and the BungeeCord proxy.
</Step>

<Step>
  ### Read the logs
  Read the proxy and server logs.
  If you find an error, send it to us on [Discord](https://skinsrestorer.net/discord).
</Step>

  <Step>
    ### Test the plugin
    Join the network and use `/skin Notch`.
  </Step>
</Steps>
