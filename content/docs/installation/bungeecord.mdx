SkinsRestorer runs on BungeeCord and each backend. The proxy manages skin commands and sends the selected profile to backends.

## Before you start

You need access to the proxy and every backend. Legacy forwarding requires backend protection. Read [backend security](/docs/troubleshooting/firewall#protect-proxy-backends) before you expose the network.

## Configure forwarding

1. Stop the proxy and backends.
2. Enable IP forwarding in the proxy configuration.
3. Enable BungeeCord forwarding on each Bukkit backend.
4. Disable account authentication on the backends.

```yaml title="BungeeCord config.yml (excerpt)"
ip_forward: true
```

```yaml title="Backend spigot.yml (excerpt)"
settings:
  bungeecord: true
```

```properties title="Backend server.properties (excerpt)"
online-mode=false
```

Keep the proxy's authentication policy separate from backend configuration. Do not disable proxy authentication just to use skins.

## Install

1. Put the server/proxy SkinsRestorer JAR in the proxy's `plugins` folder.
2. Install the same release on every backend.
3. Start the backends and proxy.
4. Read all startup logs.

A modded backend needs the matching mod artifact and compatible forwarding support. Leave backend `server.proxyMode.detection` at `AUTO` unless detection fails.

## Check

Complete the [first skin check](/docs/installation/quick-start), including a switch between backends. Grant command permissions on BungeeCord or its proxy permission plugin.

Ordinary proxy-managed skins do not require SQL storage. Backend API integrations need [shared storage](/docs/development/proxy-api).

## If it fails

If only one backend shows the skin, compare its forwarding configuration and installed release with a working backend. Use [proxy troubleshooting](/docs/troubleshooting/proxy-mode) for mode warnings and duplicate commands.
