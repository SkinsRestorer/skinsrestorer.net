SkinsRestorer работает на BungeeCord и на каждом внутреннем сервере. Прокси обрабатывает команды скинов и передаёт выбранный профиль внутренним серверам.

## Перед началом [#before-you-start]

Нужен доступ к прокси и ко всем внутренним серверам. При устаревшем (legacy) перенаправлении внутренние серверы нужно защитить. Прочитайте раздел [защита внутренних серверов](/docs/troubleshooting/firewall#protect-proxy-backends), прежде чем открывать сеть.

## Настройка перенаправления [#configure-forwarding]

1. Остановите прокси и внутренние серверы.
2. Включите перенаправление IP в настройках прокси.
3. Оставьте `online_mode: true` в `config.yml` BungeeCord. Прокси проверяет аккаунты игроков.
4. Включите перенаправление BungeeCord на каждом внутреннем сервере Bukkit.
5. Отключите аутентификацию аккаунтов на внутренних серверах.

```yaml title="config.yml BungeeCord (фрагмент)"
online_mode: true
ip_forward: true
```

```yaml title="spigot.yml внутреннего сервера (фрагмент)"
settings:
  bungeecord: true
```

```properties title="server.properties внутреннего сервера (фрагмент)"
online-mode=false
```

`online-mode=false` ставится только на внутренних серверах. Не ставьте `online_mode: false` на прокси ради скинов.

## Установка [#install]

1. Положите `SkinsRestorer.jar` в папку `plugins` прокси.
2. Установите тот же релиз на каждый внутренний сервер.
3. Запустите внутренние серверы и прокси.
4. Проверьте все логи запуска.

Внутреннему серверу Fabric или NeoForge нужен соответствующий JAR мода и мод для перенаправления. Прочитайте руководство для [Fabric](/docs/installation/fabric) или [NeoForge](/docs/installation/neoforge). Оставьте `server.proxyMode.detection` на внутренних серверах равным `AUTO`, если определение работает.

## Проверка [#check]

Выполните [первую проверку скина](/docs/installation/quick-start), включая переход между внутренними серверами. Выдавайте разрешения на команды в BungeeCord или в плагине разрешений прокси.

Обычным скинам, которыми управляет прокси, SQL-хранилище не нужно. Интеграциям с API на внутренних серверах нужно [общее хранилище MySQL или PostgreSQL](/docs/configuration/database). Настройка API описана в [руководстве по API на прокси](/docs/development/proxy-api).

## Если не работает [#if-it-fails]

Если скин виден только на одном внутреннем сервере, сравните его настройки перенаправления и версию плагина с рабочим сервером. При предупреждениях о режиме и повторяющихся командах откройте [решение проблем с прокси](/docs/troubleshooting/proxy-mode).
