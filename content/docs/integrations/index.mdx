Choose the integration for your platform. A Bukkit PlaceholderAPI expansion is not a Fabric placeholder system.

| Integration | Platform | Purpose |
| --- | --- | --- |
| [PlaceholderAPI](/docs/integrations/placeholderapi) | Bukkit-compatible servers | Selected skin identifiers and current textures |
| [DiscordSRV](/docs/integrations/discordsrv) | Bukkit-compatible servers | Player avatars in Discord |
| [Discord-MC-Chat](/docs/integrations/discord-mc-chat) | Supported DMCC mod versions | Profile texture avatars |
| [Avatar URLs](/docs/integrations/avatar-url) | Plugins with placeholder support | Render a texture as a player head |
| [MineSkin](/docs/integrations/mineskin) | Server URL generation and website uploads | Generate signed skin properties |

A proxy backend that resolves stored skin data through the API needs [shared storage](/docs/development/proxy-api). A placeholder that reads an online profile and one that reads a saved selection can return different information.

For your own Java integration, start with [the developer tutorial](/docs/development/first-plugin).
