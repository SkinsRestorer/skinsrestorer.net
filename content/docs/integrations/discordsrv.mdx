An avatar URL that uses the account UUID shows the account's original skin. An avatar URL that uses the texture hash shows the skin that SkinsRestorer applied. This guide changes DiscordSRV's player avatar to the texture hash. Complete DiscordSRV's bot and channel setup first.

## Before you start

Install SkinsRestorer, DiscordSRV, and PlaceholderAPI on the same Bukkit-compatible server. Restart the server, then [check the texture placeholder](/docs/integrations/placeholderapi).

## Configure the avatar

1. Back up `plugins/DiscordSRV/config.yml`.
2. Replace its existing `AvatarUrl` value:

```yaml title="plugins/DiscordSRV/config.yml (excerpt)"
AvatarUrl: "https://mc-heads.net/avatar/%skinsrestorer_texture_id_or_steve%.png#{texture}"
```

3. Run `/discord reload`.
4. Change your skin and send a new chat message.
5. Check the new message's avatar in Discord.

The `{texture}` fragment follows DiscordSRV's cache workaround. DiscordSRV documents both this fragment and PlaceholderAPI support in [its AvatarUrl reference](https://docs.discordsrv.com/config/#avatarurl).

## If the avatar is unchanged

Run `/papi parse me %skinsrestorer_texture_id_or_steve%` and compare the result:

- **Literal placeholder:** PlaceholderAPI or the SkinsRestorer expansion did not load.
- **`Error`:** Inspect the SkinsRestorer log.
- **Steve texture hash:** The player has no resolved skin property.
- **Correct hash, old avatar:** Open the avatar URL and compare a newly sent message. Discord and the image service can cache older avatars.

If DiscordSRV uses Discord avatars for linked accounts, also inspect that setting.

MC-Heads is an external image service. If it is unavailable, the avatar fails even when the server shows the skin correctly.

## Other plugins

The same URL works in other plugins if their avatar field expands PlaceholderAPI placeholders. Remove the `#{texture}` fragment, because it is specific to DiscordSRV. For Discord-MC-Chat, use [its own guide](/docs/integrations/discord-mc-chat).

For backend storage requirements, read [proxy API setup](/docs/development/proxy-api).
