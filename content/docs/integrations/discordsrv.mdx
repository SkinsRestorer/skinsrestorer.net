This guide changes DiscordSRV's player avatar source. Complete DiscordSRV's bot and channel setup first.

## Before you start

Install SkinsRestorer, DiscordSRV, and PlaceholderAPI on the same Bukkit-compatible server. Restart the server, then [check the texture placeholder](/docs/integrations/placeholderapi).

## Configure the avatar

1. Back up `plugins/DiscordSRV/config.yml`.
2. Replace its existing `AvatarUrl` value:

```yaml title="plugins/DiscordSRV/config.yml (excerpt)"
AvatarUrl: "https://mc-heads.net/avatar/%skinsrestorer_texture_id_or_steve%.png#{texture}"
```

3. Run `/discord reload`.
4. Change your skin and send a new chat message.
5. Check the new message's avatar in Discord.

The URL uses a skin texture hash instead of an account UUID. The `{texture}` fragment follows DiscordSRV's cache workaround. DiscordSRV documents both this fragment and PlaceholderAPI support in [its AvatarUrl reference](https://docs.discordsrv.com/config/#avatarurl).

## If the avatar is unchanged

Parse the PlaceholderAPI value first. If it is literal or `Error`, fix that before changing DiscordSRV.

If the hash is correct, open the resulting avatar URL and compare a newly sent message. Discord can cache older avatars. Also inspect DiscordSRV's linked-account avatar configuration if it uses Discord avatars.

For backend storage requirements, read [proxy API setup](/docs/development/proxy-api).
