This example applies to **Discord-MC-Chat 2.7.0's JSON configuration**. DMCC 3 uses a different configuration structure. Do not copy the JSON into a DMCC 3 YAML file.

## Before you start

Complete DMCC's bot and channel setup. Install compatible mod releases for your Minecraft version. The example uses the profile texture that the game server applies.

## Configure DMCC 2.7

1. Back up `config/discord-mc-chat.json`.
2. Find `avatarApi` inside the existing `generic` object.
3. Replace that value:

```json title="config/discord-mc-chat.json (partial object)"
{
  "generic": {
    "avatarApi": "https://mc-heads.net/avatar/{player_textures}.png"
  }
}
```

This is an excerpt. Keep the other fields in the file. The `generic.avatarApi` key and `{player_textures}` token come from the [DMCC 2.7 source](https://github.com/Xujiayao/Discord-MC-Chat/tree/2.7.0/src/main/java/com/xujiayao/discord_mc_chat).

4. Restart or use the reload command supported by your DMCC version.
5. Change a skin, then send a new chat message.
6. Check the avatar on the new message.

## DMCC 3 and other releases

Use [DMCC's documentation](https://dmcc.xujiayao.com/) for your installed version's avatar configuration and available profile placeholders. Do not assume the 2.7 token or reload syntax remains unchanged.

## If it fails

First check that another Java client sees the server-selected skin. Then check DMCC's resolved avatar URL and logs. If the game profile itself is wrong, use [skin troubleshooting](/docs/troubleshooting/no-skin).
