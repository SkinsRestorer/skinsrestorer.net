SkinsRestorer registers its expansion when PlaceholderAPI is available. You do not need to download a separate SkinsRestorer expansion from eCloud.

## Before you start

Install SkinsRestorer and [PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI) on the same Bukkit-compatible server. Restart after installation.

On a proxy backend, configure [backend API storage](/docs/development/proxy-api) if the integration needs saved selections or offline skin resolution.

## Check one placeholder

1. Select a skin with `/skin set xknat`.
2. Run `/papi parse me %skinsrestorer_texture_id_or_steve%`.
3. Check that the result is a texture hash, rather than the original placeholder text.

If the placeholder stays literal, inspect plugin loading and the consuming plugin's PlaceholderAPI support. `Error` means the expansion ran but could not provide the requested value.

## Selected skin identifier

| Placeholder | No saved selection |
| --- | --- |
| `%skinsrestorer_skin_name%` | `Error` |
| `%skinsrestorer_skin_name_or_empty%` | Empty string |
| `%skinsrestorer_skin_name_or_player_name%` | Player name |

These values describe the saved identifier. They do not guarantee that a skin is currently visible on the client.

## Texture URL

| Placeholder | No resolved skin |
| --- | --- |
| `%skinsrestorer_texture_url%` | `Error` |
| `%skinsrestorer_texture_url_or_empty%` | Empty string |
| `%skinsrestorer_texture_url_or_steve%` | Steve texture URL |
| `%skinsrestorer_texture_url_or_alex%` | Alex texture URL |

## Texture hash

| Placeholder | No resolved skin |
| --- | --- |
| `%skinsrestorer_texture_id%` | `Error` |
| `%skinsrestorer_texture_id_or_empty%` | Empty string |
| `%skinsrestorer_texture_id_or_steve%` | Steve texture hash |
| `%skinsrestorer_texture_id_or_alex%` | Alex texture hash |

Online texture placeholders read the current profile. Offline resolution uses storage and can require a service request. A request error returns `Error` and records a log entry, even for a fallback placeholder.

A texture hash is the final identifier in a Minecraft texture URL. It is different from a player UUID.
