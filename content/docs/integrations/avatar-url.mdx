An account UUID avatar can show the account's original skin. A texture-hash avatar can show the texture currently applied by SkinsRestorer.

## Before you start

The consuming plugin must support PlaceholderAPI in its avatar URL field. Install [PlaceholderAPI and check the texture placeholder](/docs/integrations/placeholderapi).

## Configure an avatar

Use this URL in the consuming plugin's avatar field:

```text
https://mc-heads.net/avatar/%skinsrestorer_texture_id_or_steve%.png
```

Reload that plugin using its supported procedure. Change the player's skin, then trigger a new avatar or message.

## Diagnose the result

- **Literal placeholder:** The field does not expand PlaceholderAPI, or the expansion did not load.
- **`Error`:** Inspect the SkinsRestorer log and data resolution.
- **Correct hash, old avatar:** Inspect the image service or consuming application's cache.
- **Steve fallback:** The placeholder has no resolved skin property.

MC-Heads is an external renderer. Its availability is separate from server skin application.
