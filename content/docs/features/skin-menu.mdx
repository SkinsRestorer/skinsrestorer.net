The skin menu is available on platforms that support its inventory UI. Your administrator controls which skins appear.

## Open the menu

Run `/skins` or `/skin menu`. Then choose **Skins Menu**, **History Menu**, or **Favourites Menu**. Click a skin to select it. Shift-click a skin to add it to your favorites, or to remove it.

The **Skins Menu** can show custom skins from the server, recommended skins, and player skins. If it is empty, the administrator can [configure its categories](/docs/configuration/skin-menu).

## Save a favorite

1. Select a skin, for example with `/skin set <name>`.
2. Run `/skin favourite`.
3. Run `/skin favourites` to list your favorites. Click an entry to use that skin again.

`/skin favourite` toggles the current skin. Run it again to remove that favorite. The command uses the British spelling `favourite`.

## Reuse a previous skin

Run `/skin history` to list your previous skins. Click an entry to use that skin again. Run `/skin undo` to go back to the skin before your current one.

The administrator sets the size of the history and the favorites list. A size of `0` turns that feature off. `/skin undo` uses the history, so it also stops working when history is off.

## Search for a skin

Run `/skin search <tag>` to get a link to the skins with that tag on NameMC, an external skin site. This command does not choose a skin for you.

To use a NameMC skin, copy the address of its skin page, then run it with `/skin`:

```text
/skin https://namemc.com/skin/SKIN_ID
```

The server treats this address as a skin URL, so you need `skinsrestorer.command.set.url`. A NameMC profile link does not work. If the server allows URLs only from some sites, download the PNG instead and [upload it](/docs/features/skin-upload).

## If access is denied

The menu needs `skinsrestorer.command.gui`. Favorites need `skinsrestorer.command.favourite`. History and undo need `skinsrestorer.command.undo`. Search needs `skinsrestorer.command.search`. Ask the administrator to check [the command reference](/docs/reference/commands-permissions).
