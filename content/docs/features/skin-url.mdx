## Before you start

Save a valid Minecraft skin PNG on your computer. The image must usually be 64x64 or 64x32 pixels.

If you need a skin, follow the [skin design guide](/docs/features/skin-design).

## Generate the command with /upload

<Steps>
  <Step>
    ### Open the /upload page

    Visit the [/upload](/upload) page on skinsrestorer.net.
    The page shows an upload area and a **Generate /skin url** button.
  </Step>

  <Step>
    ### Select your skin PNG

    Drag the file into the upload area. You can also select **Choose file**.

    Make sure that the preview shows the correct skin.
  </Step>

  <Step>
    ### Copy the generated command

    Select **Generate /skin url**. The site uploads the PNG and creates a command.

    Use the copy button or copy the `/skin url "https://..."` text.

    Paste the command into the game chat or console. Keep the URL inside quotation marks.
  </Step>
</Steps>

## Troubleshooting

- **The upload fails:** Make sure that the PNG is smaller than 3 MB and uses standard Minecraft skin dimensions.
- **The command has no quotation marks:** Put the URL inside quotation marks.
- **You changed the skin:** Upload it again to create a new URL.

You do not need a separate image host. SkinsRestorer and MineSkin process the upload.
