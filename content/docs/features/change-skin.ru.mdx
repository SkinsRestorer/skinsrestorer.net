Эти команды выполняются в чате игры. Замените `xknat` на имя аккаунта Minecraft, скин которого вам нужен.

## Смена скина [#change-your-skin]

```text
/skin set xknat
```

Дождитесь сообщения об успехе. Попросите другого игрока посмотреть на вашего персонажа. Сервер сохранит выбор для следующих входов.

`/skin xknat` работает как короткая форма. Чтобы применить свой PNG, используйте [руководство по загрузке](/docs/features/skin-upload).

## Возврат скина аккаунта [#restore-your-account-skin]

```text
/skin clear
```

Команда удаляет сохранённый выбор. После этого у вас будет скин вашего аккаунта или скин сервера по умолчанию.

## Случайный скин [#get-a-random-skin]

```text
/skin random
```

Команда выбирает случайный скин из рекомендуемых скинов SkinsRestorer. Если администратор отключил `api.fetchRecommendedSkins` или сервер не может скачать список, ничего не произойдёт.

## Обновление скопированного скина аккаунта [#refresh-a-copied-account-skin]

```text
/skin update
```

Используйте эту команду, если исходный аккаунт сменил скин или плащ. Она получает новые данные только для скина, скопированного с аккаунта игрока. Скин по URL и пользовательский скин не меняются. Чтобы изменить скин по URL, загрузите исправленное изображение и выполните новую команду.

## Если команда не работает [#if-the-command-fails]

- **Нет разрешения:** попросите администратора проверить [доступ игроков](/docs/configuration/player-access).
- **Задержка:** подождите указанное время. Повторные попытки не ускоряют запрос.
- **Скин не загружается:** проверьте имя аккаунта, затем попросите администратора проверить [подключение к сервисам](/docs/troubleshooting/firewall).
- **Успех, но скин не изменился:** используйте [решение проблем с профилем](/docs/troubleshooting/no-skin).

Чтобы отменить изменение или снова выбрать прежний скин, прочитайте про [меню скинов и избранное](/docs/features/skin-menu).
