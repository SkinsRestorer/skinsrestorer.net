Пользовательский скин даёт подписанной текстуре имя на сервере, например `lobby`. После этого игроки могут выполнить `/skin set lobby`.

## Перед началом [#before-you-start]

Нужен доступ к консоли или разрешение `skinsrestorer.admincommand.createcustom`. В сети создавайте скин через прокси, который хранит скины.

## Создание из PNG [#create-from-a-png]

1. Откройте [генератор](/generator).
2. Нажмите **Загрузить скин** и выберите PNG или выберите скин в **Библиотеке** или **Галерее**. Под командой страница поясняет, что `/sr createcustom` сохраняет скин на сервере под именем, которое игроки могут использовать с `/skin set`.
3. В разделе **Модель** выберите **Классическая** или **Тонкая**.
4. При необходимости выберите поддерживаемый плащ в разделе **Плащ**.
5. Необязательно: введите короткое имя в поле **Имя скина (необязательно)**, например `lobby`. Используйте строчные латинские буквы, цифры и подчёркивания.
6. Необязательно: откройте **Дополнительные настройки**, чтобы выбрать способ создания.
7. Нажмите **Создать /sr createcustom**.
8. Скопируйте команду и выполните её в консоли сервера или прокси.

Генератор возвращает команду. Он не скачивает файл хранилища и не устанавливает скин на ваш сервер.

Если имя не указано, команда использует имя из MineSkin, когда оно есть. Axolotl не возвращает имя, поэтому студия использует имя PNG-файла или `custom_skin`.

Генератор открывает [студию скинов](/docs/features/skin-editor) с выбранной командой `/sr createcustom`. Чтобы сначала изменить скин, нажмите **Изменить скин**. Прочитайте раздел [редактирование в загрузке и генераторе](/docs/features/skin-editor#edit-from-upload-or-generator).

## Создание по имени игрока или URL [#create-from-a-player-name-or-url]

```text
/sr createcustom lobby xknat
```

Для URL изображения оставьте URL в кавычках и укажите модель:

```text title="Замените пример URL ссылкой на настоящий PNG-скин"
/sr createcustom lobby "https://example.com/lobby.png" classic
```

Если создать скин с уже существующим именем, этот пользовательский скин обновится. Перед заменой сделайте резервную копию важных пользовательских скинов.

## Проверка и использование [#check-and-reuse]

1. Выполните `/skin set lobby` в игре.
2. Попросите другого игрока проверить вид.
3. Выполните `/sr info skin lobby`, чтобы проверить сохранённую текстуру.

Используйте `lobby` в [списке скинов по умолчанию](/docs/configuration/default-skins) или в [списке пользовательских скинов меню](/docs/configuration/skin-menu).

Чтобы изменить подпись в меню, выполните `/sr setcustomname lobby Lobby skin`. Команда использует то же разрешение, что и `createcustom`.

## Существующие файлы скинов [#existing-skin-files]

Генератор может читать поддерживаемые файлы хранилища скинов. Если скин не выбран, нажмите **Открыть файл .skin** в центре страницы. Также можно нажать **+** в **Библиотеке**, затем **Открыть файл .skin**. Текстура из файла откроется как новый скин, и её можно изменить или снова создать команду. Не редактируйте значение текстуры или подпись вручную.

Если страница показывает **Не удалось открыть файл скина**, прочитайте причину под сообщением. Выберите файл хранилища SkinsRestorer, например файл `.customskin`. Страница читает из файла только URL текстуры.

Прежде чем удалять сохранённые данные, прочитайте раздел [хранилище и резервные копии](/docs/configuration/backups).
