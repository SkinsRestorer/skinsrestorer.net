Estos comandos se escriben en el chat del juego. Cambia `xknat` por el nombre de la cuenta de Minecraft cuya skin quieres.

## Cambia tu skin [#change-your-skin]

```text
/skin set xknat
```

Espera el mensaje de éxito. Pide a otro jugador que revise tu aspecto. El servidor guarda tu selección para las próximas veces que entres.

`/skin xknat` es un atajo. Para aplicar tu propio PNG, usa [la guía de subida](/docs/features/skin-upload).

## Recupera la skin de tu cuenta [#restore-your-account-skin]

```text
/skin clear
```

Este comando quita tu selección guardada. Después tendrás la skin de tu cuenta o la skin predeterminada del servidor.

## Obtén una skin aleatoria [#get-a-random-skin]

```text
/skin random
```

Este comando elige una skin aleatoria de las skins recomendadas de SkinsRestorer. Si el administrador desactivó `api.fetchRecommendedSkins`, o el servidor no puede descargar la lista, no pasa nada.

## Actualiza una skin copiada de una cuenta [#refresh-a-copied-account-skin]

```text
/skin update
```

Úsalo cuando la cuenta original cambie su skin o su capa. Solo obtiene datos nuevos para una skin copiada de una cuenta de jugador. Una skin de URL o una skin personalizada no cambia. Para cambiar una skin de URL, sube la imagen corregida y ejecuta el nuevo comando.

## Si el comando falla [#if-the-command-fails]

- **Permiso denegado:** Pide al administrador que revise el [acceso de jugadores](/docs/configuration/player-access).
- **Tiempo de espera:** Espera el tiempo que se muestra. Repetir el intento no acelera la petición.
- **No se puede cargar la skin:** Revisa el nombre de la cuenta y pide al administrador que revise las [conexiones con los servicios](/docs/troubleshooting/firewall).
- **Éxito sin cambio visible:** Consulta [skin no visible](/docs/troubleshooting/no-skin).

Para deshacer un cambio o volver a usar una skin anterior, lee [el menú de skins y los favoritos](/docs/features/skin-menu).
