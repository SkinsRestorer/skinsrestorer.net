Esses comandos são digitados no chat do jogo. Troque `xknat` pelo nome da conta do Minecraft cuja skin você quer.

## Troque sua skin [#change-your-skin]

```text
/skin set xknat
```

Aguarde a mensagem de sucesso. Peça a outro jogador para conferir sua aparência. O servidor salva sua seleção para as próximas vezes que você entrar.

`/skin xknat` é um atalho. Para aplicar seu próprio PNG, use [o guia de envio](/docs/features/skin-upload).

## Recupere a skin da sua conta [#restore-your-account-skin]

```text
/skin clear
```

Este comando remove sua seleção salva. Depois, você volta a ter a skin da sua conta ou a skin padrão do servidor.

## Escolha uma skin aleatória [#get-a-random-skin]

```text
/skin random
```

Este comando escolhe uma skin aleatória entre as skins recomendadas. Se o servidor não tiver skins recomendadas, nada acontece.

## Atualize uma skin copiada de uma conta [#refresh-a-copied-account-skin]

```text
/skin update
```

Use depois que a conta original mudar a skin ou a capa. Ele só busca dados novos para uma skin copiada da conta de um jogador. Uma skin de URL ou uma skin personalizada continua igual. Para mudar uma skin de URL, envie a imagem revisada e execute o novo comando.

## Se o comando falhar [#if-the-command-fails]

- **Permissão negada:** peça ao administrador para conferir o [acesso dos jogadores](/docs/configuration/player-access).
- **Tempo de espera:** aguarde o tempo exibido. Tentar várias vezes não acelera o pedido.
- **A skin não carrega:** confira o nome da conta e peça ao administrador para conferir as [conexões com os serviços](/docs/troubleshooting/firewall).
- **Sucesso sem mudança visível:** consulte [skin não aparece](/docs/troubleshooting/no-skin).

Para desfazer uma troca ou usar de novo uma skin anterior, leia [o menu de skins e os favoritos](/docs/features/skin-menu).
