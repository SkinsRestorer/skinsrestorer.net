`/skin edit` gives you a browser link for your current skin. The editor does not save changes directly to the server.

## Before you start

You need `skinsrestorer.command.edit` for the editor link and `skinsrestorer.command.set.url` for the upload command.

## Edit and apply

1. Run `/skin edit` in game chat.
2. Open the editor link from the message.
3. Change the skin in the editor.
4. Export or save the two-dimensional PNG template.
5. Open [Upload](/upload).
6. Upload the PNG and choose its model.
7. Generate and run the `/skin url` command.

Editor controls can change. Save the skin template, rather than a screenshot of the three-dimensional preview.

The new selection must remain after a reconnect. If the arms show gaps, choose the other [model](/docs/features/skin-design) and generate again.

## If the link is unavailable

Use your original PNG in a skin editor, then follow [the upload guide](/docs/features/skin-upload). If the command itself is denied, ask the administrator to check the edit permission.
