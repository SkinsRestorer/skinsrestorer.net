Use `/skin edit` to open your current skin in an editor.
Then upload the changed skin and apply it.

## Editing and uploading your skin

<Steps>
  <Step>
    ### Run the command

    Run `/skin edit` in chat. SkinsRestorer gives you a link to the skin editor.

  </Step>

  <Step>
    ### Edit the skin

    Change the skin in the editor.
    Then select **Save**.

    ![Save edited skin](/assets/edit/save.png)

  </Step>

  <Step>
    ### Save the skin image

    Find the 2D skin template on the left.
    Right-click the image. Then select **Save image as**.

    ![Save image](/assets/edit/save-as.png)

  </Step>

  <Step>
    ### Upload using the /upload page

    Open the [/upload](/upload) page.
    Upload the saved skin PNG.

    The page creates a `/skin url` command.

    For more information, read the [Skin URL Upload guide](/docs/features/skin-url).

  </Step>

  <Step>
    ### Apply your skin

    Copy the command.
    Paste it into the game chat or console.

    Keep the URL inside quotation marks.

  </Step>
</Steps>
