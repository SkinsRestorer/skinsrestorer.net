Use the [skin upload page](/upload) to generate a command from a skin PNG. The page is the [Skin Studio](/docs/features/skin-editor) with the `/skin url` command selected. It does not connect to your Minecraft server. You apply the result yourself.

## Before you start

You need a Minecraft skin PNG and permission for `skinsrestorer.command.set.url`. The website accepts PNG files up to 5 MB. Use a square skin image, such as 64×64, or a legacy skin, such as 64×32. The preview also accepts scaled versions of these shapes.

Read [classic and slim models](/docs/features/skin-design) if you are unsure which model matches your image.

The page checks the image dimensions before it enables the selected file for generation. If your browser cannot show the 3D preview, you can still generate a skin command.

To fix or change the skin first, select **Edit skin** below the model. The [editor](/docs/features/skin-editor#edit-a-skin) opens in place and keeps your other choices. The page sends nothing until you select **Generate /skin url**.

## Generate and apply

1. Open [Upload](/upload).
2. Select **Upload skin** and choose your PNG, or drop the PNG on the page. You can also select a skin in **Library** or **Gallery**.
3. Check the 3D model and choose **Classic** (4 px arms) or **Slim** (3 px arms) under **Model**.
4. If you want a cape, select one under **Cape**.
5. Optional: open **Advanced options** to choose **Axolotl** or **Official** under **Upload method**. **Axolotl** is the default.
6. Select **Generate /skin url**.
7. Copy the command with the copy button next to **Command**.
8. Paste the command into your Minecraft chat.

If you change the skin, the model, the cape, or the method after you generate, the page removes the old command. Generate again to get a command for the new choices.

Keep the generated URL inside quotation marks. The command includes the model selected on the page. A result can use a MineSkin URL or an opaque `skinsrestorer-axolotl://` value.

Copy that value exactly. **Skin URL** contains the permanent texture link when MineSkin supplies one. With Axolotl, it contains the same opaque value for Minecraft commands. An Axolotl value is not a browser link.

```text title="Command shape, not a ready-to-use texture URL"
/skin url "https://textures.minecraft.net/texture/TEXTURE_HASH" slim
```

Wait for a success message. Ask another player to check your skin, then reconnect to check persistence.

## Your skins

The page keeps uploaded PNGs in the **Library** of this browser. The next time, select it there instead of uploading the file again. Keeping a skin does not send it anywhere. The page uploads the exact skin that you selected, only when you select **Generate /skin url**.

If you upload several PNG files, the page keeps all valid skins and selects the first one. It does not generate commands for the others.

The library stays in this browser only. Read [the library](/docs/features/skin-editor#your-skins) to rename, download, or remove skins. If the browser cannot keep skins, for example in some private windows, the selected skin still works on the page. The icon next to the skin name shows if the browser kept it. Point at the icon to see the reason.

Gallery skins stay separate. Read [the gallery guide](/docs/features/skin-editor#gallery) to save or edit a personal copy.

## API key and capes

The **Axolotl** method offers supported capes without your own key. The **Official** method accepts a MineSkin key and checks its cape grants. Both settings are under **Advanced options**. The cape list is always visible. A selected cape turns the model to show its back.

A selected cape with **Axolotl** uses the proxy route. **Official** uploads and uploads without a selected cape use MineSkin directly.

The key field on the website and `api.mineskinAPIKey` on your server are separate. Read [MineSkin integration](/docs/integrations/mineskin) for queues, limits, and privacy.

The available list contains supported existing capes. It does not accept arbitrary cape images or transfer cape ownership to your account.

## If generation fails

- **Invalid image:** Export a standard PNG skin template again.
- **Queue or rate limit:** Wait for the queue to finish before you retry.
- **Unauthorized key:** Check the key and its current account grants.
- **Arm artifacts:** Generate again with the [correct model](/docs/features/skin-design).
- **Command denied:** Check [URL permissions and restrictions](/docs/configuration/restrict-skins).

To give the result a reusable server name, [create a custom skin](/docs/features/custom-skins).
