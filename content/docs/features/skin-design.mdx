A skin PNG is a texture template. Each part of the image maps to the head, body, arms, or legs.

## Classic or slim

| Model | Arm width | Command value |
| --- | --- | --- |
| Classic / Steve | Four pixels | `classic` |
| Slim / Alex | Three pixels | `slim` |

The model must match the template. The wrong model can produce black lines, gaps, or misplaced arm pixels. The upload preview helps you check the result before generation.

## Image format

Use a standard **64 × 64 PNG** for a new skin. Legacy **64 × 32** skins exist, but support can depend on the upload service and conversion path.

The base body layer needs opaque pixels. The outer layer can contain transparent pixels for hats, sleeves, and other details. A standard Java client does not display arbitrary HD skin sizes.

Minecraft's Skin Customization controls can hide outer-layer parts. A hidden hat layer does not mean the server failed to apply a skin.

For format details, use [Minecraft's skin help](https://help.minecraft.net/hc/en-us/articles/4408894664461-Minecraft-Skins-for-Java-Edition).

## Prepare an image

1. Open a template in a skin editor or image editor.
2. Keep the original canvas dimensions.
3. Export a PNG without image scaling.
4. Choose the matching model on [Upload](/upload).
5. Inspect the preview before generation.

An image viewer can blur pixels during zoom. Use a pixel view to inspect the original file.
