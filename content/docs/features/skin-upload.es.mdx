La página [Subir skin](/upload) genera un comando desde una skin PNG. Es el [Estudio de skins](/docs/features/skin-editor) con el comando `/skin url` seleccionado. No se conecta a tu servidor de Minecraft. El resultado lo aplicas tú. En el juego, `/skin upload` te envía un enlace a esta página.

## Antes de empezar [#before-you-start]

Necesitas una skin PNG de Minecraft y el permiso `skinsrestorer.command.set.url`. El sitio acepta archivos PNG de hasta 5 MB. Usa una imagen de skin cuadrada, como 64×64, o una skin antigua, como 64×32. La vista previa también acepta versiones ampliadas de estas formas.

Lee [modelos clásico y delgado](/docs/features/skin-design) si no sabes qué modelo corresponde a tu imagen.

La página comprueba las dimensiones de la imagen antes de permitir la generación con el archivo elegido. Si tu navegador no puede mostrar la vista previa 3D, igualmente puedes generar el comando.

Para corregir o cambiar la skin antes, pulsa **Editar skin** debajo del modelo. El [editor](/docs/features/skin-painting) se abre en la misma página y conserva tus demás opciones. La página no envía nada hasta que pulsas **Generar /skin url**.

## Generar y aplicar [#generate-and-apply]

1. Abre [Subir skin](/upload).
2. Pulsa **Subir skin** y elige tu PNG, o suéltalo en la página. También puedes elegir una skin en **Biblioteca** o **Galería**.
3. Revisa el modelo 3D y elige **Clásica** (brazos de 4 px) o **Delgada** (brazos de 3 px) en **Modelo**.
4. Si quieres una capa, elige una en **Capa**.
5. Opcional: abre **Opciones avanzadas** y elige **Axolotl** u **Oficial** en **Método de subida**. **Axolotl** es el predeterminado.
6. Pulsa **Generar /skin url**. El botón muestra **Generando…** mientras MineSkin crea la skin. Puede tardar hasta un minuto.
7. Cuando aparezca **Tu comando está listo**, copia el comando con el botón de copiar junto a **Comando**.
8. Pega el comando en el chat de Minecraft.

Para dejar de esperar una subida lenta, pulsa **Dejar de esperar** debajo del botón. La página ignora el resultado tardío y puedes generar de nuevo.

Con el comando listo, el botón muestra **Comando listo** y queda desactivado. Si cambias la skin, el modelo, la capa o el método, la página oculta el comando anterior. Genera de nuevo para obtener un comando con las nuevas opciones.

Deja la URL generada entre comillas. El comando incluye el modelo elegido en la página. La URL del comando es un enlace de MineSkin, como `https://minesk.in/SKIN_ID`, o un valor opaco `skinsrestorer-axolotl://` de Axolotl.

```text title="Forma del comando. Tu comando tiene un ID real en lugar de SKIN_ID."
/skin url "https://minesk.in/SKIN_ID" slim
```

Copia el comando tal cual. El campo **URL de la skin**, debajo del comando, contiene el enlace permanente a la textura en `textures.minecraft.net` cuando MineSkin lo proporciona. Si no, contiene el mismo valor que el comando. Un valor de Axolotl no es un enlace para el navegador.

Espera el mensaje de éxito. Pide a otro jugador que revise tu skin y vuelve a conectarte para comprobar que se conserva.

## Tus skins [#your-skins]

La página guarda los PNG que subes en la **Biblioteca** de este navegador. La próxima vez, elige la skin ahí en lugar de subir el archivo otra vez. Guardar una skin no la envía a ningún sitio. La página sube exactamente la skin que elegiste y solo cuando pulsas **Generar /skin url**.

Si subes varios PNG, la página guarda todas las skins válidas y selecciona la primera. No genera comandos para las demás.

La biblioteca solo existe en este navegador. Lee [la biblioteca](/docs/features/skin-editor#your-skins) para renombrar, descargar o eliminar skins. Si el navegador no puede guardar skins, por ejemplo en algunas ventanas privadas, la skin seleccionada sigue funcionando en la página. El icono junto al nombre de la skin indica si el navegador la guardó. Pasa el puntero por el icono para ver el motivo.

Las skins de la galería quedan separadas. Lee [la guía de la galería](/docs/features/skin-editor#gallery) para guardar o editar una copia personal.

## Clave de API y capas [#api-key-and-capes]

El método **Axolotl** ofrece capas compatibles sin tu propia clave. El método **Oficial** acepta una clave de MineSkin y comprueba qué capas permite. Ambos ajustes están en **Opciones avanzadas**. La lista de capas siempre está visible. Al elegir una capa, el modelo gira para mostrar la espalda. Mientras la lista carga, muestra **Cargando capas…**. Si no carga, pulsa **Reintentar** debajo de la lista.

Con **Axolotl** y una capa seleccionada, la página envía la subida a Axolotl, el servicio de SkinsRestorer para subir capas. Las subidas con **Oficial** y las subidas sin capa van directamente a MineSkin. Solo **Oficial** envía tu clave de API.

La clave del sitio web y `api.mineskinAPIKey` de tu servidor son independientes. Lee [integración con MineSkin](/docs/integrations/mineskin) para ver colas, límites y privacidad.

Lee [capas](/docs/features/capes) para saber qué puede hacer y qué no una capa en un servidor.

## Si la generación falla [#if-generation-fails]

La página muestra **La skin no se subió** con el motivo. Tu skin y tus opciones se conservan. Con **Axolotl**, inténtalo de nuevo o cambia a **Oficial** en **Opciones avanzadas**. Con **Oficial**, revisa tu clave de API de MineSkin en **Opciones avanzadas** y vuelve a intentarlo. La página nunca reenvía por sí sola una subida fallida. Para más comprobaciones, lee [problemas al subir skins](/docs/troubleshooting/uploads).

- **Imagen no válida:** exporta de nuevo una plantilla de skin PNG estándar.
- **Cola o límite de solicitudes:** espera a que termine la cola antes de reintentar.
- **Clave no autorizada:** revisa la clave y los permisos actuales de su cuenta.
- **Errores en los brazos:** genera de nuevo con el [modelo correcto](/docs/features/skin-design).
- **Comando denegado:** revisa los [permisos y restricciones de URL](/docs/configuration/restrict-skins).

Para dar al resultado un nombre reutilizable en el servidor, [crea una skin personalizada](/docs/configuration/custom-skins).
