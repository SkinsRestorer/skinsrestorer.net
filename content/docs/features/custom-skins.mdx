Custom skins give a shared name to a skin. Players can apply one with `/skin <name>`.

Create a custom skin with a command or a skin file.

## Choose a custom skin name

SkinsRestorer stores custom skins in the database or in files. Each custom skin name applies to the entire server.

For example, a custom skin named `Dinnerbone` replaces the Minecraft account skin for `/skin Dinnerbone`.

Do not use a name that belongs to a player on your server. The custom skin will replace that player's account skin.

<Callout type="info" emoji="ℹ️">
  To change another player's skin, use `/skin [name] [playername]`.
  Do not create a custom skin for this task.
</Callout>

## Create a custom skin

### Run a command

Run `/sr createcustom <name> <url> <variant>` to create a custom skin from a URL.

### Skinfile Generator

The [Skinfile Generator](/generator) converts a `.png` skin file to the `.customskin` format.

<Callout type="warning" emoji="⚠️">
  The Skinfile Generator works only with file storage. If you use MySQL, run `/sr createcustom` instead.
</Callout>

Use the Skinfile Generator:

1. Save your skin as a `.png` file.
2. Open the [Skinfile Generator](/generator).
3. Select **Browse**, then select the skin file.
4. Enter an optional skin name. Use lowercase letters and no spaces.
5. Select **Upload!**.
6. Download the `name.customskin` file.
7. Put the file in `plugins/SkinsRestorer/skins`.
8. If you use a proxy, put the file on the proxy.
9. Run `/skin <name>` to apply the skin.

## Apply custom default skins

To use a custom skin as the server default:

1. Create a custom skin with one of the methods above.
2. Put the file in the skin folder on the proxy or Spigot server.
3. Enable default skins in `config.yml`.
4. Run `/sr reload`.

SkinsRestorer applies the default to players who did not select another skin.
