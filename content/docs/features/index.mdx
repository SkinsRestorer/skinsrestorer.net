Your server must have SkinsRestorer installed. A server administrator controls command access and cooldowns.

## Choose a task

- [Change or reset your skin](/docs/features/change-skin): Use a player name and restore your account skin.
- [Upload a PNG](/docs/features/skin-upload): Generate a command from your own skin image.
- [Browse skins and save favorites](/docs/features/skin-menu): Open the menu, undo a change, and reuse a skin.
- [Edit your current skin](/docs/features/skin-edit): Open an editor and apply the exported PNG.
- [Choose classic or slim](/docs/features/skin-design): Fix arm artifacts and understand the image format.
- [Use a cape](/docs/features/capes): Understand copied capes and supported upload options.

Server owners can also [create named custom skins](/docs/features/custom-skins) for a menu or default skin list.

## Before you ask for support

If a command is denied, use [permission troubleshooting](/docs/troubleshooting/permissions). If it succeeds but nothing changes, use [no visible skin](/docs/troubleshooting/no-skin).
