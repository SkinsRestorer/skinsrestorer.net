The [Skin Studio](/studio) works with Java Edition skins in your browser. It has three parts:

- **Library** on the left: the skins that this browser keeps.
- The selected skin in the center, as a 3D model that you can turn.
- Options on the right: the model, the cape, and the command to generate.

On a phone, the library opens from the **Library** button, and the options are below the model.

[Upload](/upload) and the [generator](/generator) open the same Studio. Upload always makes a `/skin url` command. The generator always makes a `/sr createcustom` command. On the Studio page, choose **Use on a server** or **Custom skin**. The Studio does not connect to your Minecraft server. For details, read [Privacy](#privacy).

## Add a skin

Select **+** in the library, then choose one of these:

- **Upload PNG**: a skin PNG up to 5 MB. You can also drop PNG files on the center of the page.
- **Create skin**: a plain classic or slim figure that you paint and save.
- **Open .skin file**: a SkinsRestorer storage file, such as `.customskin`. The Studio reads the texture URL in the file and opens that texture.
- **Open texture URL**: a texture hash or a `https://textures.minecraft.net/texture/…` URL.

The Studio adds each new skin to the library and selects it. If the same skin with the same model is already in the library, the Studio uses that skin. A selected skin shows at once, and nothing is uploaded.

The Studio accepts texture links only from `textures.minecraft.net`. For a skin from another site, download the PNG and upload it. The Studio does not look up player names.

## Browse the gallery [#gallery]

Select **Gallery** beside **Library**, or select **Browse gallery** from the empty view. Search by name, then select a skin to preview it. The gallery uses the [official recommended skins](https://github.com/SkinsRestorer/cool-skins). A normal visit does not select a skin automatically.

Browsing and selecting gallery skins do not add them to your library. Select **Save to library** below the model to keep a copy. You can also select **Edit skin** and then **Save to library** to keep an edited copy. The gallery original stays unchanged. The current command, model, cape, and advanced options work as usual.

Select **Copy gallery link** to share the original gallery skin. The link opens that public entry in Studio. Links from Upload and Generator keep the command type fixed. Your library and private edits are not included. **Download PNG** downloads the selected skin without generating a command.

## Get a command

Select a skin, check the model and the cape, then select the generate button. The [upload guide](/docs/features/skin-upload) and [custom skins](/docs/features/custom-skins) explain each command.

## Edit a skin

Select **Edit skin** below the model. The center shows the texture and the right side shows a live 3D model. The editor opens 64×64 and legacy 64×32 skins. It converts a 64×32 skin to the 64×64 layout without a message. To edit an HD skin, resize it to 64×64 in an image editor first.

1. Choose the **Base** or **Outer** layer. Tools change only the active layer.
2. Choose a tool: **Pencil**, **Eraser**, **Shade**, **Fill**, or **Pick color**.
3. Choose a color below the texture. The last eight colors that you painted with stay below the texture, also after you close the editor or reload the page. The browser keeps them on this device only.
4. Paint on the texture or on the 3D model.

The base layer is always opaque in Java Edition. For this reason, the pencil paints opaque pixels on the base layer and the eraser works only on the outer layer. The outer layer can have see-through pixels, so it also has an opacity slider.

**Fill** has two areas. Select one below the tools, or press `G` again:

- **Face** fills the connected area of one color, and stops at the edge of the face. This is the default.
- **Everywhere** replaces every pixel of exactly the clicked color, on all visible parts of the active layer. Use it to recolor a shirt in one step. A pixel of a slightly different color does not change. Hidden parts, the other layer, and unused areas do not change.

On the 3D model, a stroke stays on the face where it started.

**Shade** makes pixels lighter or darker. Select **Lighten** or **Darken** below the tools, and select a strength: **Soft**, **Medium**, or **Strong**. **Medium** is the default. **Soft** changes the lightness half as much, and **Strong** twice as much. Shade keeps the hue and the opacity of each pixel, and it does not change clear pixels. One stroke changes a pixel only one time, so you can drag over the same spot without making it darker and darker. Start a new stroke to shade it again.

**Size** sets the brush width for the pencil, the eraser, and shade, from 1 to 8 pixels. The brush is a square. An odd size is centered on the pointer. An even size reaches one more pixel up and to the left. The brush stays on the face under the pointer. The texture shows the outline of the brush. With a mouse or a pen, the 3D model also marks the pixels that the tool will change before you click. The mark is not part of the skin. A red mark and a blocked pointer mean that an outer-layer pixel covers the base layer at that spot.

**Mirror** (the flip button) also paints the other side of the model. The left arm and the right arm swap, and so do the legs. The head and the body mirror onto themselves. Mirror works with the pencil, the eraser, shade, and **Fill** with **Face**. **Everywhere** already changes every pixel of the color, so the Mirror button is not shown for it. Mirror changes only the active layer, and it does not change a hidden part. A dashed outline on the texture and a lighter mark on the 3D model show the mirrored pixels.

To draw a straight line with the pencil, the eraser, or shade, hold `Shift` and click. The line starts where your last stroke ended and uses the current size, mirror, and shade strength. A line stays on one face. If you click another face, another tool, or another layer, the click starts a new stroke instead. Undo, a model change, a fill, and a part action also start again from the next stroke.

Use **Visible parts** to hide a part or a layer. Tools do not change hidden parts. To paint the base layer under an outer-layer pixel, hide the outer layer of that part.

Each stroke, line, fill, fix, or part action is one undo step. Changing the model or converting the arms is also one undo step.

### Flip or copy a part [#flip-or-copy-a-part]

Select **Flip or copy a part** below the model. The actions change only the active layer, and they do not change a hidden part or an unused area. Each pixel keeps its color and opacity.

- **Flip left to right** shows the part as it looks in a mirror. Its left and right sides swap, and each face reverses its columns.
- **Copy without mirroring** gives one arm or leg the design of the other. Each face gets the same face of the other limb, as it is. For example, the front of the right arm becomes the front of the left arm.

To get a mirrored copy, copy the limb, and then flip the target limb.

### Change the arm width [#change-the-arm-width]

Classic arms are 4 pixels wide, and slim arms are 3 pixels wide. You can change the arm width in two ways:

- **Model** tells the game which arm width the texture has. It does not change pixels. Use it when the texture already fits the other model.
- **Convert arms to slim** or **Convert arms to classic** changes the arm pixels and the model together. Use it to make a classic skin slim, or a slim skin classic.

The conversion changes both arms, on both layers. The side faces keep every pixel. The top, bottom, front, and back are as wide as the arm, so they lose or gain one column:

- To slim: the two columns next to the body stay in place. The outer edge column stays, and the column next to it is removed.
- To classic: the middle column of the slim arm is copied into the new column. No empty stripe appears.

Arm pixels that the new model does not use become clear. The head, the body, the legs, and other pixels do not change. Converting to slim removes one column, so converting back does not restore it. Undo restores the original pixels and the model. If the texture already fits the other model, select the model instead. A conversion would move the empty column into the arm.

### Move the view

Select the hand button to scroll the texture and turn the model with one finger or the mouse. Select the brush button to use the tool again. In paint mode, one finger paints, and a right drag turns the model. Two fingers scroll the texture or turn the model, and a stroke that the first finger started is removed. On a touch screen, **Fill** and **Pick color** work when you lift the finger, so a two-finger gesture never fills by accident.

### Keyboard

| Key | Action |
| --- | --- |
| `B` | Pencil |
| `E` | Eraser |
| `S` | Shade. Press again to switch between lighten and darken. |
| `G` | Fill. Press again to switch between **Face** and **Everywhere**. |
| `I` | Pick color |
| `X` | Mirror on or off |
| `[` / `]` | Smaller or larger brush |
| `L` | Switch between the base and outer layer |
| `P` / `M` | Paint or move view |
| `Shift` and click | A straight line from the end of the last stroke |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Esc` | Cancel editing |

To paint with the keyboard, move the focus to the texture with `Tab`. The arrow keys move a pixel cursor, and `Shift` with an arrow key moves four pixels. `Space` or `Enter` uses the tool. `Shift+Space` or `Shift+Enter` draws a straight line to the cursor. A screen reader reads the part, face, layer, and position of the cursor. The shortcuts do nothing while a text field has the focus.

## Skin check

While you edit, the Studio checks for problems that change how the skin looks in Java Edition. It shows an alert only when it finds a problem.

The check does not change pixels. A fix runs only when you select its button, and you can undo it. Select **Show pixels** to mark the affected pixels on the texture.

| Problem | Fix |
| --- | --- |
| See-through base pixels | **Make opaque** keeps each color and sets it to opaque, which is how the game shows it. |
| Pixels in unused areas | **Clear unused areas** removes pixels that the game does not show. |
| The skin may be classic or slim | **Use classic** or **Use slim** changes the model. This is a guess, so look at the preview first. With the slim model, the game ignores the wide arm column. With the classic model, an empty fourth column can show as a dark stripe. These buttons do not change pixels. To change the arm pixels, read [Change the arm width](#change-the-arm-width). |

An opaque outer layer is not a problem. Some skins use it on purpose.

## Save your work

- **Save changes** writes your changes to the skin in the library. The skin keeps its original file, so you can revert to it later.
- **Save as copy** adds a new skin with your changes and selects it. The skin that you opened does not change.
- **Cancel** returns to the skin that was selected before.

For a new skin from **Create skin**, **Save to library** adds it to the library.

The model, cape, upload method, API key, and skin name stay as you set them while you edit, save, or cancel.

An icon next to the name shows the save state. Point at the icon to see it:

| Icon | State |
| --- | --- |
| Check mark | Saved in the library. |
| Dot | Unsaved changes, or a new skin that is not saved yet. |
| Spinner | Saving. |
| Crossed-out disk | The browser cannot keep this skin. |

If you edit the same skin in two tabs and save in one tab first, the other tab does not overwrite it. It asks you to save your work as a copy or to replace the other version. If another tab removed the skin, you can save your work as a copy.

If you select **Cancel**, press `Esc`, or use the browser Back button with unsaved changes, the Studio asks first. You can keep editing, discard the changes, or keep them as a draft.

## Drafts

While you paint, the Studio keeps a draft of your unsaved changes in this browser. The draft does not change the saved skin. Each open editor has its own draft, so two tabs do not overwrite each other.

If you close the tab before you save, the draft stays. The next time you open the Studio, it asks if you want to continue the draft. **Continue** opens the draft. **Discard** deletes it. The Studio does not keep the undo history.

Earlier versions of the editor kept one draft in another place in the browser. The Studio moves that draft to the library once, as a skin named "Recovered draft". If the old draft is damaged, the Studio keeps it and shows a message with a **Discard draft** button.

If your browser blocks site storage or the storage is full, the Studio still works, but it does not keep skins or drafts. Use the download button above the texture to keep your work. In this case, the browser asks before you leave the page with unsaved changes.

## The library [#your-skins]

The Studio, Upload, and the generator share one library in this browser. A skin in the library keeps its original file and its current version, the model for each, and its name.

- The library stays only in this browser on this device. It does not sync to other devices or accounts.
- If you clear the site data, or if the browser removes old site data, the library is deleted. Use **Download PNG** to keep a copy of a skin.
- Select a skin once to use it. Each skin has a menu with **Rename**, **Duplicate**, **Download PNG**, **Revert to original**, and **Remove**.
- A dot on a skin means that it has unsaved edits in a draft.
- After you remove a skin, select **Undo** in the message to get it back.
- The check mark next to **Library** means that the browser keeps your skins. A crossed-out disk means that it cannot. Point at the icon to see the reason.

## Edit from Upload or Generator [#edit-from-upload-or-generator]

[Upload](/upload) and the [generator](/generator) have the same **Edit skin** button and the same editor. When you save, the edited skin is selected, and the page keeps its other choices. The page sends nothing until you select its generate button.

Old links to the editor page open the Studio. A link with a texture hash opens that texture in the Studio.

## Privacy

Browsing Gallery downloads its catalog from `cool-skins.skinsrestorer.net` and thumbnails from `textures.minecraft.net`. Selecting a gallery skin downloads its PNG from the texture server. These reads do not upload your local skins.

Editing, the library, drafts, and PNG downloads happen in your browser. The Studio does not send your skin image to SkinsRestorer or to any other server until you select a generate button. Adding, renaming, or removing a skin in the library does not send it either.

If you open a texture URL or a `.skin` file, your browser downloads the texture from `textures.minecraft.net`. The generate button sends the selected PNG to MineSkin, directly or through the SkinsRestorer Axolotl proxy. Read [MineSkin integration](/docs/integrations/mineskin) for more.

## If the 3D model does not show

The 3D model needs WebGL. If your browser turns off WebGL or loses the graphics context, the Studio shows a message instead. Editing the texture, the skin check, generating, and the download still work. In the editor, select **Try again** to start the model again.
