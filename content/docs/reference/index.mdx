## Configuration keys

Each page below lists the exact keys and defaults of one part of `config.yml`. Edit the existing sections in the active `config.yml`. On Bukkit, the file is `plugins/SkinsRestorer/config.yml`.

| Section | Page | What it controls |
| --- | --- | --- |
| `storage` | [Storage settings](/docs/reference/storage) | Default skins and the durations of the skin and UUID caches. |
| `commands` | [Command settings](/docs/reference/commands) | Cooldowns, restrictions, history, favorites, and command registration. |
| `database` | [Database configuration](/docs/reference/database) | The storage backend and the SQL connection. |
| `login`, `server`, `proxy` | [Server, login, and proxy behavior](/docs/reference/server) | Join behavior, skin refresh, sound, proxy detection on backends, and command limits by backend name on the proxy. |
| `api` | [External services](/docs/reference/services) | MineSkin keys, recommended skins, account lookup batches, and Ely.by. |
| `gui` | [Skin menu configuration](/docs/reference/gui) | Menu categories and entries. |
| `messages`, `dev` | [Messages and diagnostics](/docs/reference/messages) | Locales, the message prefix, dates, and `dev.debug`. |
| `advanced` | [Advanced behavior](/docs/reference/advanced) | Join application, refresh workarounds, and external connections. |

The `server` keys apply to backends. They do not configure the proxy itself. The `proxy` keys apply only to the proxy.

## Correct common outdated keys

- Use `database.type: MYSQL` or `POSTGRESQL` for new SQL configuration. The plugin migrates earlier `database.enabled` configuration.
- `commands.perSkinPermissions` is a boolean, not a section with `enabled` and `list`.
- Use `api.mineskinAPIKey` and `api.mineskinSecretSkins` with that exact capitalization.
- Use `gui.custom` and `gui.custom.onlyShowList`, rather than `customSkins` and `onlyList`.
- Use `proxy.notAllowedCommandServers.ifNoServerBlockCommand`.
- Mount refresh keys include `OnSkinUpdate`, such as `server.dismountPlayerOnSkinUpdate`.

## Apply an excerpt

Edit the matching section in the existing file. Do not paste duplicate top-level keys. Use `/sr reload` for ordinary changes. Restart after storage, proxy detection, or command registration changes.
