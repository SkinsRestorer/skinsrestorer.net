`<argument>` é obrigatório. `[argument]` é opcional. `a|b` indica aliases. `/skinsrestorer` é um alias de `/sr`. Coloque entre aspas um nome de skin, uma entrada de skin ou uma URL que tenha espaços.

No console, digite os comandos sem a barra inicial. Comandos sem `<selector>` agem sobre quem os executa, por isso só funcionam no jogo. As formas curtas `/skin <skinName> <selector>` e `/skull <skinName> <selector>` também só funcionam no jogo. No console, use `/skin set` ou `/skull get`. O `/sr purgeolddata` só funciona no console. O modo proxy muda quais comandos um servidor registra.

## Permissões especiais [#special-permissions]

| Permissão | Finalidade |
| --- | --- |
| `skinsrestorer.player` | Grupo de jogador integrado: comandos para si mesmo e o menu. Todo jogador o tem por padrão. |
| `skinsrestorer.command.*` | Outra forma de conceder o grupo de jogador integrado |
| `skinsrestorer.admin` | Grupo de administrador integrado: contém o grupo de jogador e as ações sobre outros jogadores |
| `skinsrestorer.admincommand.*` | Outra forma de conceder o grupo de administrador integrado |
| `skinsrestorer.bypasscooldown` | Ignora os tempos de espera dos comandos |
| `skinsrestorer.bypassdisabled` | Ignora os nomes de skin bloqueados |
| `skinsrestorer.ownskin` | Permite escolher o nome da própria conta quando as permissões por skin estão ativadas |
| `skinsrestorer.skin.<name>` | Permite escolher uma skin específica |

O grupo de administrador integrado não contém `reload`, `dump` nem `purgeolddata`. Nenhum grupo integrado contém `skinsrestorer.command.skull` nem `skinsrestorer.ownskin`. Conceda esses nós explicitamente quando precisar. `skinsrestorer.command.skull` controla apenas `/skull` e `/skull help`.

O SkinsRestorer lê os dois nós curinga como nomes de grupos. Um plugin de permissões que expande curingas por conta própria pode conceder mais. Por exemplo, ele pode tratar `skinsrestorer.command.*` como uma concessão de `skinsrestorer.command.set.other`.

Use [acesso dos jogadores](/docs/configuration/player-access) para configurar os grupos. Use [restrições de skins](/docs/configuration/restrict-skins) para nomes bloqueados, prefixos de URL, acesso por skin e consentimento obrigatório.

## Seletores de alvo e ações administrativas [#target-selectors-and-administrative-behavior]

Um `<selector>` aceita um ou mais alvos:

- O nome de um jogador online. Uma correspondência exata tem prioridade sobre uma que ignora maiúsculas e minúsculas.
- O UUID de um jogador.
- `-all` para todos os jogadores online.
- `-random` para um jogador online aleatório.

Junte vários alvos com `+`, por exemplo `/sr applyskin Steve+Alex`.

`/skin set <skinName> <selector>` muda a seleção salva do alvo. `/sr applyskin <selector>` aplica de novo a skin definida para o alvo.

`/skin notification ignore-cracked-client` dispensa o aviso sobre clientes em modo offline. O comando só fica disponível enquanto o jogador não tiver dispensado o aviso.

`/sr createcustom` salva uma skin com nome. `/sr setcustomname` muda o nome exibido e usa a mesma permissão. `drop` e `purgeolddata` apagam dados salvos, então [faça uma cópia de segurança antes](/docs/configuration/backups).

`/skin favourite` adiciona ou remove a seleção atual dos favoritos. `history` usa a permissão `undo`. `search`, `edit` e `upload` fornecem links para o navegador; eles não salvam sozinhos uma imagem editada.

`/sr status` verifica os serviços de contas. `/sr dump` envia um relatório de diagnóstico. Leia [coletar diagnósticos](/docs/troubleshooting/debugging) para saber o que cada um inclui.

## Modo proxy [#proxy-mode]

Execute os comandos de jogador e a administração do armazenamento pelo proxy. Em modo proxy, um backend registra apenas `/sr`, `/sr help [query]`, `/sr status` e `/sr dump`. Ele não registra `/skin`, `/skins`, `/skull` nem os outros comandos `/sr`.

## Tempos de espera [#cooldowns]

Trocas de skin e pedidos de cabeças têm, cada um, um tempo de espera padrão de 30 segundos. Depois de um erro, o tempo de espera padrão é de 5 segundos. `skinsrestorer.bypasscooldown` ignora esses tempos de espera.

Use a [configuração de comandos](/docs/reference/commands) para mudar as durações.
