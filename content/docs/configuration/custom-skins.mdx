A custom skin gives a signed texture a server-owned name, such as `lobby`. Players can then use `/skin set lobby`.

## Before you start

You need console access or `skinsrestorer.admincommand.createcustom`. Run the command on the proxy (or on the server, if you have no proxy).

## Create from a PNG

1. Open [Generator](/generator).
2. Select **Upload skin** and choose your PNG, or select a skin in **Library** or **Gallery**.
3. Choose **Classic** or **Slim** under **Model**.
4. Select a supported cape under **Cape** if you need one.
5. Optional: enter a short name under **Skin name (optional)**, such as `lobby`. Use lowercase letters, numbers, and underscores.
6. Optional: open **Advanced options** to choose the generation method.
7. Select **Generate /sr createcustom**.
8. Copy the command and run it in the server or proxy console.

The Generator page returns a command. It does not download a storage file or install the skin on your server.

If you leave the name empty, the command uses the name of the PNG file, such as `forest_ranger` for `Forest ranger.png`. For a skin in the library, this is its library name. If no usable name is left, the command uses `custom_skin`. The empty field shows this name as a placeholder.

The Generator page is the [Skin Studio](/docs/features/skin-editor) with the `/sr createcustom` command selected. To change the skin first, select **Edit skin** to open the editor. Read [Edit from Upload or Generator](/docs/features/skin-editor#edit-from-upload-or-generator).

## Create from a player name or URL

```text
/sr createcustom lobby xknat
```

For an image URL, keep the URL quoted and specify the model:

```text title="Replace the example URL with a real skin PNG"
/sr createcustom lobby "https://example.com/lobby.png" classic
```

Creating an existing name updates that custom skin. Back up valuable custom skins before replacement.

## Check and reuse

1. Run `/skin set lobby` in game.
2. Check the appearance from another player.
3. Run `/sr info skin lobby` to inspect the stored texture.

Use `lobby` in a [default skin list](/docs/configuration/default-skins) or the [custom menu list](/docs/configuration/skin-menu).

To change the menu label, run `/sr setcustomname lobby Lobby skin`. The command uses the same permission as `createcustom`.

## Existing skin files

The Generator page can read supported existing skin storage files. When no skin is selected, select **Open .skin file** in the center of the page. You can also select **+** in the **Library**, then **Open .skin file**. The texture of the file opens as a new skin, so you can edit it or generate a command again. Do not hand-edit a texture value or signature.

If the page shows **This skin file could not be opened**, read the reason below it. Choose a SkinsRestorer storage file, such as a `.customskin` file. The page reads only the texture URL in the file.

Read [storage and backups](/docs/configuration/backups) before you remove stored data.
