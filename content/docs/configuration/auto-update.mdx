SkinsRestorer looks for updates when the server starts. If an update exists, it downloads the file.

SkinsRestorer installs the update during the next server restart.

<Callout type="info" emoji="ℹ️">
  On BungeeCord and Velocity networks, only backend servers update automatically.
  When SkinsRestorer reports an update, update the proxy manually.
</Callout>

## Why automatic updates are enabled

Updates contain security fixes, bug fixes, and new features. The project supports only the latest version.

Before you request support, update SkinsRestorer. The latest version can already contain a fix for your problem.

## Benefits of the latest version

- **Security:** The latest version contains current security fixes.
- **Features:** The latest version contains current features and bug fixes.
- **Support:** The project provides support only for the latest version.
- **Compatibility:** The latest version contains current compatibility fixes.

## Update security

SkinsRestorer compares the downloaded file's hash with the GitHub release. This comparison detects damaged or different files.

Automated tests and project testers examine each release before publication.

## Disable automatic updates

The project does not provide support for installations with automatic updates disabled.

The automatic updater reduces manual work and shows an in-game message when an update is available.

If you still want to disable it, read the instructions at the bottom of `config.yml`.
