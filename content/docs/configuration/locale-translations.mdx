SkinsRestorer uses locale files and MiniMessage text. Player messages and console messages have separate locale configuration.

## Select the locale

Edit the existing `messages` section:

```yaml title="config.yml (SkinsRestorer excerpt)"
messages:
  locale: "en"
  consoleLocale: "en"
  perIssuerLocale: false
  disablePrefix: false
  dateFormat: "dd MMMM yyyy"
```

With `perIssuerLocale: true`, a player's client locale can take priority over the configured default. Use `false` if all players must receive the same language.

Run `/sr reload`, then check a player message and the console. Use a locale code supported by the installed release.

## Customize messages

1. Back up the `locales` directory inside the SkinsRestorer data folder.
2. Open the locale file for the language in use.
3. Change the message text without removing its placeholders.
4. Keep the JSON valid.
5. Run `/sr reload`.
6. Trigger the changed message with a test account.

The bundled default file is `locales/locale.json`. Inspect the generated directory for the exact filenames of other languages.

MiniMessage tags control formatting. A placeholder such as `<name>` supplies data from the command. Removing it can make a message less useful.

## Custom command help

`commands.customHelp.enabled` and `commands.customHelp.message` replace the configured `/skin` help text. They do not replace every command error or subcommand message.

## Contribute a translation

Use the [SkinsRestorer translation project](https://translate.skinsrestorer.net). Keep technical names and placeholders unchanged.

For configuration defaults, read [messages and diagnostics](/docs/reference/messages).
