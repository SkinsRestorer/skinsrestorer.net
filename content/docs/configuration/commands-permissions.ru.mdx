`<argument>` обязателен. `[argument]` необязателен. `a|b` перечисляет псевдонимы. URL и аргументы из нескольких слов оставляйте в кавычках.

Команды только для игроков выполняйте в игре. В консоли команды вводятся без начального слеша. Доступность команд зависит от платформы и режима прокси.

## Особые разрешения [#special-permissions]

| Разрешение | Назначение |
| --- | --- |
| `skinsrestorer.player` | Встроенная группа игрока: обычные команды для себя и меню |
| `skinsrestorer.command.*` | Альтернативный способ выдать встроенную группу игрока |
| `skinsrestorer.admin` | Встроенная группа администратора: группа игрока и действия над другими игроками |
| `skinsrestorer.admincommand.*` | Альтернативный способ выдать встроенную группу администратора |
| `skinsrestorer.bypasscooldown` | Обход задержки между командами |
| `skinsrestorer.bypassdisabled` | Обход запрещённых имён скинов |
| `skinsrestorer.ownskin` | Выбор имени своего аккаунта, когда включены разрешения на отдельные скины |
| `skinsrestorer.skin.<name>` | Выбор отдельного разрешённого скина |

Встроенная группа администратора не включает `reload`, `dump` и `purgeolddata`. При необходимости выдайте эти разрешения явно. Плагин разрешений может обрабатывать `*` по-своему.

Командам может также требоваться доступ к родительской команде. Корневые разрешения: `skinsrestorer.command`, `skinsrestorer.admincommand` и `skinsrestorer.command.skull`.

Группы настраиваются в разделе [доступ игроков](/docs/configuration/player-access). Запрещённые имена, префиксы URL, доступ к отдельным скинам и обязательное согласие описаны в разделе [ограничение скинов](/docs/configuration/restrict-skins).

## Селекторы целей и действия администратора [#target-selectors-and-administrative-behavior]

`<selector>` указывает одного или нескольких игроков через парсер селекторов платформы. Сначала используйте точное имя игрока. Поддержка селекторов зависит от платформы.

`/skin set <skinName> <selector>` меняет сохранённый выбор цели. `/sr applyskin <selector>` повторно применяет скин, определённый для цели. Команд `setskinall` и `applyskinall` в этом релизе нет.

`/sr createcustom` сохраняет именованный скин. `/sr setcustomname` меняет его отображаемое имя и использует то же разрешение. `drop` и `purgeolddata` удаляют сохранённые данные, поэтому [сначала сделайте резервную копию](/docs/configuration/backups).

`/skin favourite` добавляет текущий скин в избранное или убирает его оттуда. `history` использует разрешение `undo`. `search`, `edit` и `upload` дают ссылки на сайт и сами не сохраняют изменённое изображение.

`/sr status` проверяет сервисы аккаунтов. `/sr dump` загружает диагностический отчёт. Что входит в каждый из них, описано в разделе [сбор диагностики](/docs/troubleshooting/debugging).

## Режим прокси [#proxy-mode]

Обычные команды игроков и управление хранилищем выполняйте через прокси. Внутренние серверы в режиме прокси поддерживают локальные `/sr status` и `/sr dump`. Другие команды там могут быть недоступны, и так задумано.

## Задержки [#cooldowns]

По умолчанию смена скина и запрос головы имеют задержку 30 секунд. Задержка после ошибки по умолчанию 5 секунд. `skinsrestorer.bypasscooldown` позволяет обходить эти задержки.

Длительность меняется в [настройках команд](/docs/reference/commands).
