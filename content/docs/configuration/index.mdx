## Change configuration safely

1. Back up the active configuration file.
2. Edit the existing section in `config.yml`.
3. Keep YAML indentation consistent.
4. Apply the change with `/sr reload` or a restart, as the guide specifies.
5. Repeat the task that the configuration controls.

Do not paste a second copy of the same top-level section. A YAML parser can replace one copy silently.

On Bukkit servers, the file is `plugins/SkinsRestorer/config.yml`. On other platforms, use the data directory reported at startup.

The [configuration reference](/docs/configuration/options) lists exact keys and defaults. Command registration, storage changes, and platform forwarding need a restart.
