`<argument>` is required. `[argument]` is optional. `a|b` lists aliases. Keep URLs and multi-word quoted arguments inside quotation marks.

Run player-only commands in game. Console commands omit the leading slash. Availability depends on the platform and proxy mode.

## Special permissions

| Permission | Purpose |
| --- | --- |
| `skinsrestorer.player` | Built-in player group: ordinary self-service commands and the menu |
| `skinsrestorer.command.*` | Alternate grant for the built-in player group |
| `skinsrestorer.admin` | Built-in admin group, including the player group and other-player operations |
| `skinsrestorer.admincommand.*` | Alternate grant for the built-in admin group |
| `skinsrestorer.bypasscooldown` | Bypass command cooldowns |
| `skinsrestorer.bypassdisabled` | Bypass blocked skin names |
| `skinsrestorer.ownskin` | Select your own account name with per-skin permissions enabled |
| `skinsrestorer.skin.<name>` | Select an individual permitted skin |

The built-in admin group omits `reload`, `dump`, and `purgeolddata`. Grant those nodes explicitly when needed. A permission plugin can interpret wildcards differently.

Commands can require their parent command access too. The root nodes are `skinsrestorer.command`, `skinsrestorer.admincommand`, and `skinsrestorer.command.skull`.

Use [player access](/docs/configuration/player-access) to configure groups. Use [skin restrictions](/docs/configuration/restrict-skins) for per-skin access and required consent.

## Target selectors and administrative behavior

A `<selector>` identifies the target player or players through the platform's selector parser. Use an explicit player name first. Selector support can depend on the platform.

`/skin set <skinName> <selector>` changes a target's saved selection. `/sr applyskin <selector>` reapplies the skin resolved for the target. There are no `setskinall` or `applyskinall` commands in this release.

`/sr createcustom` stores a named skin. `/sr setcustomname` changes its display label and uses the same permission. `drop` and `purgeolddata` remove stored data, so [back up first](/docs/configuration/backups).

`/skin favourite` toggles the current selection in favorites. `history` uses the `undo` permission. `search`, `edit`, and `upload` provide browser links rather than saving an edited image themselves.

`/sr status` checks account services. `/sr dump` uploads a diagnostic report. Read [diagnostic collection](/docs/troubleshooting/debugging) for what each includes.

## Proxy mode

Run normal player commands and storage administration through the proxy. Proxy-mode backends provide local `/sr status` and `/sr dump`. Other commands can be unavailable there by design.

## Cooldowns

Skin changes and skull requests each use a 30-second cooldown by default. Their error cooldowns default to 5 seconds. `skinsrestorer.bypasscooldown` bypasses these cooldowns.

Use [command configuration](/docs/reference/commands) to change the durations.
